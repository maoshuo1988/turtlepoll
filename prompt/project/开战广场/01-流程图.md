# 开战广场流程图

## 1. 创建赌局

```mermaid
flowchart TD
  A["用户提交创建赌局"] --> B["校验登录和表单"]
  B --> C{"是否私人局"}
  C -- "是" --> D{"邀请码是否存在"}
  C -- "否" --> E["按公开局创建"]
  D -- "否" --> F["返回邀请码必填"]
  D -- "是" --> G["按私人局创建"]
  E --> H["创建 Battle"]
  G --> H
  H --> I["创建庄家 BattleBet"]
  I --> J["扣庄家本金入资金池"]
  J --> K["写 BattleLedger"]
  K --> L["返回赌局"]
```

## 2. 加入或追加下注

```mermaid
flowchart TD
  A["挑战者提交加入"] --> B["锁定 Battle"]
  B --> C{"状态是否 open"}
  C -- "否" --> D["拒绝加入"]
  C -- "是" --> E{"是否庄家本人"}
  E -- "是" --> F["拒绝加入"]
  E -- "否" --> G{"是否私人局"}
  G -- "是" --> H{"邀请码是否正确"}
  H -- "否" --> I["返回邀请码错误"]
  H -- "是" --> J["检查幂等下注"]
  G -- "否" --> J
  J --> K{"是否已存在 requestId"}
  K -- "是" --> L["返回已有下注"]
  K -- "否" --> M["校验剩余容量"]
  M --> N{"是否超过容量"}
  N -- "是" --> O["返回剩余可下注额"]
  N -- "否" --> P["计算入场费"]
  P --> Q["创建挑战者 BattleBet"]
  Q --> R["扣本金入资金池"]
  R --> S["公开局转入场费给庄家"]
  S --> T["更新汇总金额"]
  T --> U{"是否满额"}
  U -- "是" --> V["状态改为 sealed"]
  U -- "否" --> W["保持 open"]
  V --> X["提交事务"]
  W --> X
```

## 3. 状态轮巡

```mermaid
flowchart TD
  A["后台轮巡 battle"] --> B["扫描 open 或 sealed"]
  B --> C{"是否到结算时间"}
  C -- "否" --> D{"是否容量满"}
  D -- "是" --> E["open 改为 sealed"]
  D -- "否" --> F["保持当前状态"]
  C -- "是" --> G{"是否有玩家加入"}
  G -- "否" --> H["结果标记为 timeout"]
  H --> I["生成结算单：庄家可提取返还本金"]
  I --> M["Battle 结束"]
  G -- "是" --> J["进入 pending"]
  J --> K["写 pendingDeadline"]
  K --> L["等待庄家宣判"]
```

## 4. 庄家宣判

```mermaid
flowchart TD
  A["庄家提交结果"] --> B["锁定 Battle"]
  B --> C{"是否庄家"}
  C -- "否" --> D["返回无权限"]
  C -- "是" --> E{"状态是否 pending"}
  E -- "否" --> F["拒绝宣判"]
  E -- "是" --> G{"结果是否合法"}
  G -- "否" --> H["返回结果非法"]
  G -- "是" --> I["写 result 和 resultBy"]
  I --> J["写 confirmDeadline"]
  J --> K["等待挑战者确认或异议"]
```

## 5. 挑战者确认与异议

```mermaid
flowchart TD
  A["挑战者提交动作"] --> B["锁定 Battle"]
  B --> C{"状态是否 pending"}
  C -- "否" --> D["拒绝操作"]
  C -- "是" --> E{"是否挑战者"}
  E -- "否" --> F["返回仅挑战者可操作"]
  E -- "是" --> G{"是否已有动作"}
  G -- "是" --> H["幂等返回当前 Battle"]
  G -- "否" --> I{"动作类型"}
  I -- "确认" --> J["写 confirm action"]
  I -- "异议" --> K["写 dispute action"]
  J --> L{"是否全部确认"}
  L -- "是" --> M["生成结算单"]
  L -- "否" --> N["等待其他挑战者"]
  K --> O["进入 disputed"]
  O --> P["写 disputeDeadline"]
```

## 6. 管理员裁决

```mermaid
flowchart TD
  A["管理员提交裁决"] --> B["校验管理员权限"]
  B --> C["锁定 Battle"]
  C --> D{"状态是否 disputed"}
  D -- "否" --> E["拒绝裁决"]
  D -- "是" --> F{"裁决结果是否合法"}
  F -- "否" --> G["返回结果非法"]
  F -- "是" --> H["按规则计算处罚"]
  H --> I["写 burn 流水"]
  I --> J["生成结算单"]
  J --> K["Battle 进入 settled"]
```

## 7. 提取

```mermaid
flowchart TD
  A["用户请求提取"] --> B["读取结算明细"]
  B --> C{"Battle 是否 settled"}
  C -- "否" --> D["拒绝提取"]
  C -- "是" --> E{"是否已有可提取明细"}
  E -- "否" --> F["返回无可提取金额"]
  E -- "是" --> G{"是否已提取"}
  G -- "是" --> H["幂等返回明细"]
  G -- "否" --> I["从资金池出池到用户"]
  I --> J["写 payout 流水"]
  J --> K["标记 withdrawn"]
```

## 8. 互动热度

```mermaid
flowchart TD
  A["用户评论或点赞"] --> B{"实体是否 battle"}
  B -- "否" --> C["走原实体热度规则"]
  B -- "是" --> D["写评论或点赞数据"]
  D --> E["Battle.heat 增加"]
  E --> F["列表可按热度排序"]
```
