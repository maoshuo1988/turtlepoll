# 开战广场初始化数据说明

## 1. 账户初始化

系统首次启用开战广场前，必须初始化以下系统账户：

| 数据项 | 值 | 说明 |
|---|---|---|
| 资金池账户 userId | -1 | 托管所有下注本金 |
| 销毁账户 userId | -2 | 接收处罚 burn |

初始化约束：

- 若账户已存在，初始化脚本必须幂等跳过。
- 账户余额初始值为 0。
- 账户类型标记为系统账户，不允许登录。

## 2. 配置初始化

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `battle.minStakeAmount` | 100 | 最小庄家押注 |
| `battle.publicEntryFeeRate` | 0.05 | 公开局入场费 |
| `battle.privateEntryFeeRate` | 0 | 私人局入场费 |
| `battle.inviteCode.length` | 4 | 邀请码长度 |
| `battle.inviteCode.charset` | A-Za-z0-9 | 邀请码字符集 |
| `battle.inviteCode.ttlSeconds` | 86400 | 邀请码 TTL（24h） |
| `redis.host` | 127.0.0.1 | Redis 地址 |
| `redis.port` | 6379 | Redis 端口 |

## 3. 验收检查项

- 能创建公开局并扣除庄家本金到资金池账户。
- 能创建私人局并返回 4 位邀请码。
- 私人局邀请码在 24 小时后自动失效。
- 私人局邀请码大小写混输仍可校验通过。
- 公开局加入后入场费实时进入庄家账户。
- 处罚场景下 burn 金额进入销毁账户。
