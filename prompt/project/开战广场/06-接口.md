# 开战广场接口

## 1. Iris MVC 路由防错提示词

请检查接口 URL 与 Iris MVC 实际路由是否一致，并严格遵守以下规则：

1. 文档 URL 是最终契约，代码必须服务文档 URL。
2. 不要假设方法名里的下划线 `_` 会自动映射成短横线 `-`。
3. 当 URL 包含短横线，例如 `/ability-options`、`/kill-switch`，必须使用 `BeforeActivation` 显式绑定。
4. 当 URL 包含多级路径，例如 `/market/settle`、`/comment_reward/logs`，必须使用 `BeforeActivation` 显式绑定。
5. 显式绑定格式示例：

```go
func (c *PetController) BeforeActivation(b mvc.BeforeActivation) {
	b.Handle("GET", "/ability-options", "GetAbility_options")
}
```

6. controller 文件需要导入：

```go
import "github.com/kataras/iris/v12/mvc"
```

7. 新增接口后必须用文档 URL 做本地 curl 验证，不能只跑单测。
8. curl 返回 HTML 首页通常表示路由未命中并被 SPA fallback 接住；返回 JSON 的“请先登录/无权限”才表示已经命中后端。
9. 对 `/api/admin/**` 接口，验证时同时检查认证方式：cookie 名通常是 `bbsgo_token`，也可用 `Authorization: Bearer <token>`。
10. 如果已有接口使用自动映射且 URL 含下划线，可以保留；但新增文档 URL 使用短横线时必须显式绑定，避免线上 404 或 HTML fallback。

## 2. 统一响应

成功：

```json
{
  "success": true,
  "data": {}
}
```

失败：

```json
{
  "success": false,
  "message": "battle not found"
}
```

## 3. 用户接口

所有 `/api/battle/**` 接口需要登录。

### 3.1 赌局列表

- URL：`GET /api/battle/list`

Query：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 默认 1 |
| pageSize | int | 否 | 默认 20，最大 100 |
| status | string | 否 | open/sealed/pending/disputed/settled |
| listScope | string | 否 | public/private，默认 public |
| mine | string | 否 | `1` 表示与我相关 |
| role | string | 否 | banker/challenger，优先级高于 mine |
| sort | string | 否 | latest/heat/big/settle_soon |

设计要求：

- `listScope=public`：公共广场列表，仅返回公开局（`isPublic=true`）。
- `listScope=private`：私人广场列表，仅返回与我相关的私人局（`isPublic=false`）。
- 私人广场“与我相关”定义：我是庄家，或我作为挑战者下注过。
- 未传 `listScope` 时默认按公共广场处理（等价 `listScope=public`）。
- `role=banker/challenger` 在 `listScope=private` 下继续生效，用于过滤“我创建的私人局”或“我参与的私人局”。
- 兼容参数 `mine=1` 继续保留：当未传 `listScope` 且传入 `mine=1` 时，返回与我相关的公开局和私人局混合列表（历史行为）。
- 传入非法 `listScope` 时返回 `invalid listScope`。

#### 3.1.1 公共广场列表

- 场景参数：`listScope=public`
- 目标：公开发现页
- 数据范围：仅公开局
- 安全要求：不得返回私人局

示例：

```http
GET /api/battle/list?listScope=public&page=1&pageSize=20&sort=heat
```

#### 3.1.2 私人广场列表

- 场景参数：`listScope=private`
- 目标：我的私人局聚合页
- 数据范围：与我相关的私人局
- 安全要求：不支持未登录或非关联用户遍历私人局

示例（我的私人庄家局）：

```http
GET /api/battle/list?listScope=private&role=banker&page=1&pageSize=20
```

示例（我参与的私人挑战局）：

```http
GET /api/battle/list?listScope=private&role=challenger&page=1&pageSize=20
```

返回：

| 字段 | 说明 |
|------|------|
| list | 赌局列表 |
| count | 总数 |
| page | 当前页 |
| pageSize | 每页数量 |

列表项：

| 字段 | 说明 |
|------|------|
| battle | Battle |
| myAction | 当前用户确认或异议动作 |
| bankerNickname | 庄家昵称 |
| commentCount | 评论数 |
| likeCount | 点赞数 |

### 3.2 赌局详情

- URL：`GET /api/battle/by?battleId=1`

Query：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| battleId | int64 | 是 | 赌局 ID |
| inviteCode | string | 否 | 私人局授权码，4 位字母数字，大小写不敏感 |
| refreshInvite | string | 否 | `1` 表示刷新邀请码，仅私人局庄家可用 |

设计要求：

- 公开局按 `battleId` 可直接查询。
- 私人局按 `battleId` 查询仅以下任一条件可见：庄家、已参与挑战者、携带有效 `inviteCode`。
- 私人局未授权时统一返回 `battle not found`。
- 私人局庄家查询时返回当前 `inviteCode` 与 `inviteExpireAt`。
- 私人局庄家传 `refreshInvite=1` 时触发生成新邀请码并立即使旧邀请码失效。
- 邀请码刷新后的有效期固定 48 小时。

返回：

| 字段 | 说明 |
|------|------|
| battle | Battle |
| myAction | 当前用户动作 |
| settlement | 结算单 |
| settlement.myItem | 当前用户结算明细 |
| inviteCode | 私人局庄家可见的邀请码 |
| inviteExpireAt | 私人局庄家可见的邀请码过期时间（秒级时间戳） |

### 3.3 创建赌局

- URL：`POST /api/battle/create`
- Content-Type：`application/json`

Body：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | string | 是 | 议题标题 |
| bankerSide | string | 是 | 庄家立场 |
| challengerSide | string | 是 | 挑战者立场 |
| stakeAmount | int64 | 是 | 庄家本金，最小 100 |
| isPublic | bool | 是 | 是否公开 |
| settleTime | int64 | 是 | 秒级时间戳 |
| requestId | string | 建议 | 创建幂等键 |

示例：

```json
{
  "title": "巴萨 vs 皇马，谁赢？",
  "bankerSide": "巴萨",
  "challengerSide": "皇马",
  "stakeAmount": 1000,
  "isPublic": false,
  "settleTime": 1760000000,
  "requestId": "create-001"
}
```

设计要求：

- 私人局邀请码不允许客户端传入，创建时由服务端自动生成。
- 邀请码规则：4 位字母数字（`[A-Za-z0-9]{4}`），大小写不敏感。
- 邀请码默认有效期 48 小时。
- 服务端使用 Redis `127.0.0.1:6379` 生成并校验邀请码唯一性。

返回补充字段（私人局）：

| 字段 | 说明 |
|------|------|
| inviteCode | 服务端自动生成的邀请码（4 位） |
| inviteExpireAt | 邀请码过期时间（秒级时间戳） |

### 3.4 加入或追加下注

- URL：`POST /api/battle/join`
- Content-Type：`application/json`

Body：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| battleId | int64 | 是 | 赌局 ID |
| amount | int64 | 是 | 本金金额 |
| requestId | string | 是 | 幂等键 |
| inviteCode | string | 私人局必填 | 邀请码 |

说明：

- 公开局收取 amount 的 5% 入场费。
- 私人局不收入场费。
- 同一用户可多次追加下注，但每次必须使用新的 requestId。
- 私人局邀请码必须满足 4 位字母数字格式，大小写不敏感。
- 私人局邀请码默认 48 小时过期，过期后返回邀请码失效错误。
- 私人局邀请码必须命中 Redis 且与 `battleId` 一致。

### 3.5 庄家加注

- URL：`POST /api/battle/banker_add_stake`
- Content-Type：`application/json`

Body：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| battleId | int64 | 是 | 赌局 ID |
| amount | int64 | 是 | 加注本金 |
| requestId | string | 是 | 幂等键 |

### 3.6 庄家宣判

- URL：`POST /api/battle/declare`
- Content-Type：支持 `application/x-www-form-urlencoded` 与 `application/json`

Body：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| battleId | int64 | 是 | 赌局 ID |
| result | string | 是 | banker_wins/banker_loses |

说明：

- 服务端优先读取表单参数；当表单未提供 `battleId/result` 时回退读取 JSON body。

### 3.7 挑战者确认

Body：

| 字段 | 类型 | 必填 | 说明 |

| battleId | int64 | 是 | 赌局 ID |
| requestId | string | 是 | 幂等键 |
| remark | string | 否 | 备注 |

### 3.8 挑战者异议

## 4. 统计接口

### 4.1 赌局统计

- URL：`GET /api/battle/stats`

返回未结算资金池、开放局数量、争议数量等聚合数据。

## 5. 管理员接口

所有 `/api/admin/battle/**` 接口需要管理员权限。

### 5.1 管理员裁决

- URL：`POST /api/admin/battle/resolve`
- Content-Type：`application/json`

Body：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| battleId | int64 | 是 | 赌局 ID |
| requestId | string | 是 | 幂等键 |
| result | string | 是 | banker_wins/banker_loses/void |
| remark | string | 否 | 裁决备注 |

### 5.2 手动触发轮巡

- URL：`POST /api/admin/battle/cron_tick`

仅用于运营和排障，生产环境应限制调用频率。

### 5.3 趋势数据

- URL：`GET /api/admin/battle/trends?range=7d`

返回每日新增 battle 数。

### 5.4 活跃下注用户

- URL：`GET /api/admin/battle/active_users?range=7d`

返回每日去重下注用户数。

## 6. 高频错误 message

| message | 建议中文提示 |
|---------|--------------|
| `battle not found` | 赌局不存在，或私人局无访问权限 |
| `battleId is required` | 缺少赌局 ID |
| `title is required` | 请输入议题标题 |
| `sides are required` | 请输入双方立场 |
| `stakeAmount must be >= 100` | 庄家押注不能低于 100 |
| `inviteCode is required for private battle` | 私人局必须填写邀请码 |
| `inviteCode format invalid` | 邀请码格式错误，需为 4 位字母数字 |
| `invalid inviteCode` | 邀请码错误 |
| `inviteCode expired` | 邀请码已过期 |
| `only banker can refresh inviteCode` | 仅庄家可刷新邀请码 |
| `refresh inviteCode only for private battle` | 仅私人局支持刷新邀请码 |
| `battle is not open` | 当前赌局不可加入 |
| `battle is full` | 赌局已满 |
| `amount exceeds remaining capacity` | 下注超过剩余额度 |
| `banker cannot join as challenger` | 庄家不能挑战自己的局 |
| `permission denied` | 无权限操作 |
| `battle is not pending` | 当前阶段不能执行该操作 |
| `battle is not disputed` | 当前赌局不在争议中 |
| `battle is not settled` | 赌局尚未结算 |
| `no payout for this user` | 当前用户没有可提取金额 |
| `insufficient balance` | 余额不足 |
