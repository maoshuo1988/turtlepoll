# 开战广场 ER 关系图

## 1. 核心 ER

```mermaid
erDiagram
    BATTLE ||--o{ BATTLE_BET : has
    BATTLE ||--o{ BATTLE_LEDGER : has
    BATTLE ||--o{ BATTLE_CHALLENGE_ACTION : has
    BATTLE ||--|| BATTLE_SETTLEMENT : has
    BATTLE_SETTLEMENT ||--o{ BATTLE_SETTLEMENT_ITEM : has

    USER ||--o{ BATTLE : banker
    USER ||--o{ BATTLE_BET : place
    USER ||--o{ BATTLE_CHALLENGE_ACTION : action
    USER ||--o{ BATTLE_SETTLEMENT_ITEM : receive

    USER_COIN ||--o{ USER_COIN_LOG : audit

    BATTLE {
      int64 id PK
      string title
      int64 banker_user_id FK
      bool is_public
      string invite_code
      int64 invite_code_expire_at
      string status
      int64 settle_time
      int64 pending_deadline
      int64 confirm_deadline
      int64 dispute_deadline
      string result
      int64 banker_stake_total
      int64 challenger_stake_total
      int64 pool_principal_total
      int64 entry_fee_total
      int64 burn_total
    }

    BATTLE_BET {
      int64 id PK
      int64 battle_id FK
      int64 user_id FK
      string role
      int64 amount
      int64 entry_fee
      string request_id
    }

    BATTLE_LEDGER {
      int64 id PK
      int64 battle_id FK
      int64 user_id FK
      string action
      int64 amount
      string request_id
    }

    BATTLE_CHALLENGE_ACTION {
      int64 id PK
      int64 battle_id FK
      int64 user_id FK
      string action
      string request_id
    }

    BATTLE_SETTLEMENT {
      int64 id PK
      int64 battle_id FK
      string result
    }

    BATTLE_SETTLEMENT_ITEM {
      int64 id PK
      int64 settlement_id FK
      int64 battle_id FK
      int64 user_id FK
      int64 payout_amount
      bool withdrawn
      string withdraw_request_id
    }

    USER {
      int64 id PK
    }

    USER_COIN {
      int64 user_id PK
      int64 balance
    }

    USER_COIN_LOG {
      int64 id PK
      int64 user_id FK
      string biz_type
      int64 amount
      int64 biz_id
    }
```

## 2. 关键约束

- `battle_settlement` 对 `battle_id` 唯一，一局只生成一张结算单。
- `battle_settlement_item` 对 `battle_id + user_id` 唯一，每人每局一条提取记录。
- `battle_bet` 对 `battle_id + user_id + request_id` 唯一，保证加入/追加幂等。
- `battle_ledger` 对 `battle_id + user_id + action + request_id` 唯一，保证流水幂等。
- `battle_challenge_action` 对 `battle_id + user_id` 唯一，挑战者确认和异议二选一。
- 私人局邀请码有效性以 Redis 为准，`invite_code` 与 `invite_code_expire_at` 用于展示和审计。
