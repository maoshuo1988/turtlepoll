# 开战广场配置与数据模型

## 1. 配置项

| 配置 | 默认值 | 说明 |
|------|--------|------|
| 最小庄家押注 | 100 | 创建赌局押注本金下限 |
| 公开局入场费率 | 5% | 公开局挑战者下注时额外收取 |
| 私人局入场费率 | 0% | 私人局不收入场费 |
| 庄家宣判窗口 | 24h | 进入 pending 后庄家宣判期限 |
| 挑战者确认窗口 | 24h | 庄家宣判后挑战者确认或异议期限 |
| 管理员仲裁窗口 | 24h | disputed 后管理员裁决期限 |
| 轮巡频率 | 1min 到 5min | 用于状态自动迁移 |
| 资金池账户 | `BattlePoolUserId` | 托管下注本金 |
| 销毁账户 | `BattleBurnUserId` | 接收处罚 burn |

## 2. 状态枚举

| 状态 | 值 | 说明 |
|------|----|------|
| 开放中 | `open` | 可加入、可追加、庄家可加注 |
| 已封盘 | `sealed` | 不再加入，等待到期 |
| 待确认 | `pending` | 等待庄家宣判或挑战者确认 |
| 争议中 | `disputed` | 等待管理员裁决 |
| 已结算 | `settled` | 已生成结算单，可提取 |

## 3. 结果枚举

| 结果 | 值 | 说明 |
|------|----|------|
| 庄家赢 | `banker_wins` | 庄家获得资金池本金 |
| 庄家输 | `banker_loses` | 挑战者按比例获得庄家本金 |
| 作废 | `void` | 挑战者退本金，庄家退 90%，10% burn |

## 4. Battle

`Battle` 是赌局主表。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int64 | 赌局 ID |
| title | string | 议题标题 |
| bankerUserId | int64 | 庄家用户 ID |
| bankerSide | string | 庄家立场 |
| challengerSide | string | 挑战者立场 |
| isPublic | bool | 是否公开 |
| inviteCode | string | 私人局邀请码 |
| status | string | open/sealed/pending/disputed/settled |
| settleTime | int64 | 结算时间 |
| pendingDeadline | int64 | 庄家宣判截止 |
| confirmDeadline | int64 | 挑战者确认截止 |
| confirmedCount | int64 | 已确认人数冗余 |
| disputeDeadline | int64 | 管理员裁决截止 |
| disputedByUserId | int64 | 发起争议用户 |
| result | string | banker_wins/banker_loses/void |
| resultBy | string | banker/timeout/admin/system |
| resultTime | int64 | 结果产生时间 |
| bankerStakeTotal | int64 | 庄家本金总额 |
| challengerStakeTotal | int64 | 挑战者本金总额 |
| poolPrincipalTotal | int64 | 资金池本金总额 |
| entryFeeTotal | int64 | 入场费累计 |
| burnTotal | int64 | 销毁累计 |
| heat | int64 | 热度 |
| createTime | int64 | 创建时间 |
| updateTime | int64 | 更新时间 |

索引建议：

- `status`。
- `isPublic`。
- `settleTime`。
- `heat`。
- `bankerUserId`。
- `inviteCode`。

## 5. BattleBet

`BattleBet` 是下注明细，庄家创建、庄家加注、挑战者加入、挑战者追加都写入。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int64 | 明细 ID |
| battleId | int64 | 赌局 ID |
| userId | int64 | 用户 ID |
| role | string | banker/challenger |
| amount | int64 | 本金金额 |
| entryFee | int64 | 入场费 |
| requestId | string | 幂等键 |
| createTime | int64 | 创建时间 |
| updateTime | int64 | 更新时间 |

唯一约束：

- `battleId + userId + requestId`。

结算口径：

- 按 `battleId + userId + role` 汇总 amount。
- 不按单笔下注分别派奖。

## 6. BattleLedger

`BattleLedger` 是 battle 领域业务流水，用于和金币流水对账。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int64 | 流水 ID |
| battleId | int64 | 赌局 ID |
| userId | int64 | 用户 ID |
| action | string | stake_in/entry_fee/entry_fee_income/burn/payout |
| requestId | string | 幂等键 |
| amount | int64 | 正数入账，负数出账 |
| remark | string | 备注 |
| createTime | int64 | 创建时间 |

唯一约束：

- `battleId + userId + action + requestId`。

## 7. BattleChallengeAction

记录挑战者确认或异议。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int64 | 动作 ID |
| battleId | int64 | 赌局 ID |
| userId | int64 | 挑战者 ID |
| action | string | confirm/dispute |
| requestId | string | 幂等键 |
| remark | string | 异议备注 |
| createTime | int64 | 创建时间 |

唯一约束：

- `battleId + userId`，确认和异议二选一。

## 8. BattleSettlement

结算单主表。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int64 | 结算单 ID |
| battleId | int64 | 赌局 ID |
| result | string | 最终结果 |
| createdAt | int64 | 创建时间 |

唯一约束：

- `battleId`。

## 9. BattleSettlementItem

结算单明细。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int64 | 明细 ID |
| settlementId | int64 | 结算单 ID |
| battleId | int64 | 赌局 ID |
| userId | int64 | 用户 ID |
| payoutAmount | int64 | 可提取金额 |
| withdrawn | bool | 是否已提取 |
| withdrawRequestId | string | 提取幂等键 |
| withdrawTime | int64 | 提取时间 |
| createTime | int64 | 创建时间 |
| updateTime | int64 | 更新时间 |

唯一约束：

- `battleId + userId`。

## 10. 与金币模型关系

- `UserCoin` 记录用户金币余额。
- `UserCoinLog` 记录账户扣款、转账、出池、销毁流水。
- `BattleLedger` 记录 battle 业务语义流水。
- 两类流水都必须可通过 battleId 或 bizId 关联审计。
