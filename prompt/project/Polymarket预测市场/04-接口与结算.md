# Polymarket接口与结算

## 1. 同步接口

### 1.1 当前手动同步

```text
POST /api/football/sync_polymarket
```

认证：

- 需要登录。

代码：

```text
FootballController.PostSync_polymarket()
  -> PolymarketSyncService.SyncMarkets(ctx)
```

说明：

- 同步范围来自 `bbs-go.yaml`。
- 接口不接收 tag 或 slug 参数。
- 当前不是管理员接口。

### 1.2 建议新增管理员同步

建议：

```text
POST /api/admin/predict/sync_polymarket
```

原因：

- Polymarket 同步属于运营能力。
- 应使用 `AdminMiddleware`。
- 方便记录 operate-log。
- 避免普通登录用户触发外部 API 同步。

## 2. 市场查询

Polymarket 市场写入后复用统一查询：

```text
GET /api/football/markets
GET /api/football/markets/by_tag
GET /api/football/markets/by_name
GET /api/football/predict_context/hot
```

返回聚合：

```text
market: PredictMarket
context: PredictContext
betSettleResult
hasBet
```

筛选建议：

- 可通过 `sourceModel=Polymarket` 筛出 Polymarket 来源市场。
- 可通过 tag `polymarket` 查询。

## 3. 下注

接口：

```text
POST /api/coin/bet
```

认证：

- 需要登录。

参数：

```text
marketId
option=A/B
amount
```

当前规则：

- 只允许 `PredictMarket.status=OPEN`。
- 到达 `closeTime` 后拒绝下注。
- Polymarket 市场当前按二元市场处理。
- odds 使用站内池算法，不使用 Polymarket 外部赔率。

资金动作：

```text
UserCoin.balance -= amount
UserCoinLog: BET
PredictBet: OPEN
PredictMarket.poolA/poolB += amount
```

## 4. 运营结算

接口：

```text
POST /api/admin/predict/market/settle
```

认证：

- 管理员。

请求：

```json
{
  "marketId": 1,
  "result": "A",
  "requestId": "manual-001",
  "remark": "manual settle",
  "allowReset": false
}
```

当前规则：

- `result` 必须匹配市场类型。
- `binary` 允许 `A/B`。
- `1x2` 允许 `A/B/DRAW`。
- 默认只允许 `CLOSED/CLOSE -> SETTLED`。
- `allowReset=true` 时允许重设已结算市场。

写入：

```text
PredictMarket.status = SETTLED
PredictMarket.result = A/B/DRAW
PredictMarket.resolved = true
PredictMarket.resolvedAt = now if empty
OperateLog
```

### 4.1 Polymarket 当前结算方式

当前 Polymarket resolved 同步不会自动写 `result`。

因此 Polymarket 市场的真实闭环是：

```text
Gamma 同步
  -> 写 PredictMarket.resolved/resolvedOutcomeName
  -> status=CLOSE
运营查看 resolvedOutcomeName
  -> 手动调用 admin settle
  -> 写 result=A/B
用户调用 /api/coin/settle
  -> 派奖
```

## 5. 用户结算

接口：

```text
POST /api/coin/settle
```

认证：

- 需要登录。

参数：

```text
marketId
```

规则：

- 市场必须是 `SETTLED`。
- `PredictMarket.result` 必须是合法选项。
- 只结算当前用户 `OPEN` 下注。
- 幂等：重复结算不会重复派奖。

派奖：

```text
option == result:
  settleResult = WIN
  payout = floor(amount * lockedOdds)

option != result:
  settleResult = LOSE
  payout = 0
```

资金动作：

```text
PredictBet.status = SETTLED
PredictBet.settleResult = WIN/LOSE
PredictBet.payout = payout
PredictBet.settleTime = now
UserCoin.balance += payout
UserCoinLog: SETTLE
AI settlement push event
```

## 6. 当前完整闭环

当前已实现闭环：

```text
Polymarket Gamma
  -> SyncMarkets
  -> PredictMarket + PredictContext
  -> 用户列表查看
  -> 用户下注
  -> 运营人工结算
  -> 用户结算领取
```

当前未实现闭环：

```text
Polymarket Gamma resolved
  -> 自动识别 winner
  -> 自动映射 A/B
  -> 自动 SETTLED
  -> 用户直接领取
```
