# 撕裂带总览与边界

## 1. 目标

- 在预测场景中引入可持续对线讨论场域，形成可量化热度对抗。
- 对暗盘事件提供双层结算能力，确保下注收益与讨论收益解耦。
- 对开撕台提供回合制对决能力，支持长期话题循环运营。

## 2. 业务对象

- 事件: 预测市场事件（暗盘）。
- 下注对象: 取自预测市场下注对象，支持二元 `A/B` 或三元 `A/B/C`（`C` 对应平局 `DRAW`）。
- 用户行为: 围绕预测市场的下注与预测市场评论（含回复、点赞）。
- 热度: 点赞热度 + 评论热度 + 投币热度。

## 3. 状态机边界

暗盘状态机复用预测市场状态机，不重复定义:

- [预测市场状态机（创建到下注）](../预测市场公共部分/01-流程图.md#1-通用市场创建到下注)
- [预测市场状态机（运营结算）](../预测市场公共部分/01-流程图.md#3-运营人工结算)

开撕台单局状态（基于预测市场状态机映射）:

- 下注期: 市场 `OPEN` 且 `now < lockTime`。
- 锁局期: 市场 `OPEN` 且 `lockTime <= now < closeTime`（业务层禁止下注，仅保留评论互动）。
- 冷却期: 市场 `SETTLED` 且 `now < settledTime + cooldownSeconds`。

## 4. 能力边界

本设计包含:

- 站队锁定规则
- 热度口径与计算
- 结算池定义与分配
- 接口契约与错误码
- 配置项与初始化数据

本设计不包含:

- 前端视觉规范细节（仅保留字段与状态要求）
- 推荐系统分发算法
- 反作弊模型训练细节

## 5. 一致性规则

- 下注后下注对象永久锁定，不可撤销。
- 顶层预测市场评论只能发在本人下注对象下，回复允许跨对象。
- 点赞只能给同下注对象内容。
- 热度结算窗口关闭后，互动不再影响热度。

## 6. 成功标准

- 暗盘: 可完成双层结算且结果可审计。
- 开撕台: 可按预测市场结算时一同稳定结算并完成清场。
- 统一口径: 同一事件内热度计算结果可复算。
