# 撕裂带初始化数据说明

## 1. 初始化目标

- 初始化开撕台 16 个固定话题。
- 初始化撕裂带默认配置。
- 初始化赛季与回合基线数据。

## 2. 初始化顺序

1. 写入基础配置 `tear.*`。
2. 创建 `ARENA` 场景 16 个话题模板。
3. 生成当前赛季 `season_no=1`。
4. 为每个话题创建 `round_no=1` 事件。

## 5. 初始化校验

- 话题模板数量必须为 16。
- 每个模板都必须存在首局 `round_no=1`。
- 初始化后 `ARENA` 场景不存在重复 `topic_code + round_no`。

## 6. 回滚策略

- 初始化失败时按批次回滚事务。
- 若已生成部分事件，按 `init_batch_id` 全量删除重建。
