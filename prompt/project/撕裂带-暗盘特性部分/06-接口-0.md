# 撕裂带接口

## 1. 用户侧接口

### 1.1 查询事件详情

- Method: `GET`
- URL: `/api/tear/event/{eventId}`

响应字段:

- `eventId` bigint
- `sceneType` string
- `status` string
- `optionA` object
- `optionB` object
- `optionC` object (仅三元市场返回)
- `heat` object
- `countdownSeconds` int

### 1.2 下注并锁定阵营

- Method: `POST`
- URL: `/api/tear/bet`

请求:

```json
{
  "eventId": 123,
  "option": "A",
  "amount": 200,
  "requestId": "bet-uuid"
}
```

响应:

```json
{
  "betId": 1001,
  "option": "A",
  "locked": true,
  "odds": 1.83
}

字段说明:

- `option`: 预测市场下注对象，取值 `A/B` 或 `A/B/C`（`C` 对应平局 `DRAW`）。
```

### 1.3 发表顶层评论

- Method: `POST`
- URL: `/api/tear/comment`

请求:

```json
{
  "eventId": 123,
  "option": "A",
  "content": "观点内容",
  "images": []
}
```

规则:

- 顶层评论 option 必须等于用户锁定下注对象。
- 未锁定用户可通过该动作形成弱锁定。

### 1.4 回复评论

- Method: `POST`
- URL: `/api/tear/reply`

请求:

```json
{
  "eventId": 123,
  "parentCommentId": 5566,
  "content": "楼中楼回复"
}
```

规则:

- 允许跨下注对象回复。
- 热度按回复者下注对象归属。

### 1.5 点赞

- Method: `POST`
- URL: `/api/tear/like`

请求:

```json
{
  "eventId": 123,
  "targetCommentId": 5566
}
```

规则:

- 仅可点赞同下注对象作者内容。
- 同目标仅允许一次点赞。

## 2. 运营侧接口

### 2.1 触发暗盘结算

- Method: `POST`
- URL: `/api/admin/tear/event/settle`

请求:

```json
{
  "eventId": 123,
  "resultOption": "A",
  "settleVersion": 1
}
```

### 2.2 查询结算批次

- Method: `GET`
- URL: `/api/admin/tear/settle_batches?eventId=123`

响应:

- `batches[]` 包含 `settleType/status/retryCount/poolAmount`。

### 2.3 重试失败结算

- Method: `POST`
- URL: `/api/admin/tear/settle_retry`

请求:

```json
{
  "settleBatchId": 99001
}
```

## 3. 错误码

| 错误码 | 场景 |
|------|------|
| TEAR_EVENT_NOT_FOUND | 事件不存在 |
| TEAR_STATUS_INVALID | 当前状态不允许该操作 |
| TEAR_CAMP_LOCKED | 阵营已锁定且与请求不一致 |
| TEAR_CAMP_CONFLICT | 与弱锁定阵营冲突 |
| TEAR_AMOUNT_INVALID | 下注金额非法 |
| TEAR_REPEAT_LIKE | 重复点赞 |
| TEAR_IDEMPOTENT_HIT | 幂等命中，不重复执行 |
| TEAR_SETTLE_RETRY_EXCEEDED | 超过最大重试次数 |

## 4. 路由绑定要求

- 多级路径与短横线路由需 `BeforeActivation` 显式绑定。
- 所有接口 URL 以本章节为唯一契约来源。
