# 龟种配置与等级详情

## 龟种字段

- **龟种 ID**：业务枚举，如 `basic`、`stone`、`lava`。
- **名称**：面向用户展示的龟种名称。
- **稀有度**：C / B / A / S / SS / SSS。
- **小游戏能力**：下海捕捞基础能力，以及护盾、缩小等附加能力。
- **特殊能力**：影响签到、抽奖、对赌、利息、补贴、体力消耗等规则。

## 等级系统

- 每只龟独立计算等级与经验值。
- 最高等级：10。
- 经验值仅计入当前装备龟种。
- 满级后经验不再增加。
- 升级所需经验：从第 N 级升至第 N+1 级需要 `50 + 20 * N` XP。

| 当前等级 | 升至下一级所需 XP | 累计总 XP |
| --- | --- | --- |
| Lv.1 -> Lv.2 | 70 | 70 |
| Lv.2 -> Lv.3 | 90 | 160 |
| Lv.3 -> Lv.4 | 110 | 270 |
| Lv.4 -> Lv.5 | 130 | 400 |
| Lv.5 -> Lv.6 | 150 | 550 |
| Lv.6 -> Lv.7 | 170 | 720 |
| Lv.7 -> Lv.8 | 190 | 910 |
| Lv.8 -> Lv.9 | 210 | 1120 |
| Lv.9 -> Lv.10 | 230 | 1350 |

## 经验来源

| 行为 | 经验值 | 说明 |
| --- | --- | --- |
| 喂龟粮 | +1 XP | 每个苹果计入当前装备龟 |
| AI 对话 | +5 XP | 完成一次对话后计入 |
| 投票下注 | +3 XP | 下注成功后即时计入 |
| 投票下注金额 | +1 XP / 100 龟币 | 向下取整 |
