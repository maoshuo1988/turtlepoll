## 依赖优先级

- **P0（必须）**：AI 体力、下注回调、小游戏、对赌、金币、赛季、灰度配置。
- **P1（计划中）**：成就解锁（可选）。

## 通知/订阅关系

```
宠物系统 -> AI 系统：订阅 AI 对话前体力检查
宠物系统 -> 预测市场：订阅 下注成功、市场结算事件
宠物系统 -> 小游戏：订阅 得分上报、奖励加成查询
宠物系统 -> 好友对赌：订阅 对赌结算事件
宠物系统 -> 金币系统：调用 扣减/发放接口
宠物系统 -> 成就系统：调用 装扮解锁（可选）
宠物系统 -> 赛季系统：调用 排名查询
宠物系统 -> 配置系统：调用 灰度配置查询
```
