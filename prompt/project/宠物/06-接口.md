# 宠物系统接口

> 本文是宠物领域接口摘要。详细请求响应示例以 `docs/api/user_pet.md`、`docs/api/pet.md`、`docs/api/pet_gacha.md` 为准。

## Iris MVC 路由防错提示

设计和实现接口前需要检查接口 URL 与 Iris MVC 实际路由一致：

1. 文档 URL 是最终契约，代码必须服务文档 URL。
2. 不要假设方法名里的下划线 `_` 会自动映射成短横线 `-`。
3. URL 包含短横线或多级路径时，必须使用 `BeforeActivation` 显式绑定。
4. curl 返回 HTML 首页通常表示路由未命中并被 SPA fallback 接住；返回 JSON 的“请先登录/无权限”才表示命中后端。
5. 对 `/api/admin/**` 接口，需要同时检查 cookie `bbsgo_token` 或 `Authorization: Bearer <token>`。

示例：

```go
func (c *PetController) BeforeActivation(b mvc.BeforeActivation) {
	b.Handle("GET", "/ability-options", "GetAbility_options")
}
```

## 通用约定

- 用户侧 Base URL：`/api/pet`
- 运营侧 Base URL：`/api/admin/pet`
- 金额/数量统一使用整数。
- 日切统一使用北京时间 UTC+8 0 点。
- 用户侧接口需要登录态。
- 管理端接口需要登录态和管理员权限。

## 用户侧接口

### 登录触发每日结算

- 接口：项目现有登录接口。
- 行为：登录成功后尝试执行每日结算。
- 返回：在登录响应中增加 `dailySettle`。
- 幂等：同一用户同一北京日期只结算一次。
- 失败策略：结算失败不阻断登录，返回错误信息用于观测。

`dailySettle` 建议字段：

- `date`
- `alreadySettled`
- `balanceBefore`
- `balanceAfter`
- `items[]`
- `streak.loginStreak`
- `pet.petId`
- `pet.petKey`
- `pet.level`
- `errorCode`
- `errorMsg`

### 当前装备龟种

- `GET /api/pet/equip`

返回：

- `pet`：统一宠物展示对象。
- `petId`、`petKey`、`petName`、`rarity`：兼容字段。
- `abilities`、`abilityDescriptions`：能力配置和可展示说明。
- `level`
- `equippedAt`
- `equipDayName`

### 切换龟种

- `POST /api/pet/equip`

请求：

- `petId` 或 `petKey`。

校验：

- 已达到每日切换限制：`EQUIP_DAILY_LIMIT`。
- 欠款未还清：`DEBT_UNPAID`。
- 未拥有该龟种：`PET_NOT_OWNED` 或 `PARAM_INVALID`。

响应：

- `ok`
- `pet`
- `nextEffectiveAt`

### 用户拥有龟种列表

- `GET /api/pet/owned`

返回：

- `items[]`
- 每项包含统一 `pet` 对象、`level`、`xp`、`obtainedAt`、是否当前装备。

### 开蛋

- `GET /api/pet/gacha/config`
- `POST /api/pet/gacha/open`

行为：

- 普通用户可读取当前开蛋池配置，不需要管理员权限。
- 解析当前生效配置快照。
- 计算实际费用。
- 扣除龟币。
- 抽取龟种。
- 重复时返还实际费用的 30%。
- 返回抽取结果、是否重复、返还金额和余额变化。

### 体力与龟粮

- `GET /api/pet/stamina`
- `POST /api/pet/stamina/restore`

行为：

- 查询当前体力。
- 购买苹果恢复体力。
- 装备糖果龟时应用价格折扣。
- 写金币流水和体力流水。

## 运营侧接口

### 龟种定义

- `GET /api/admin/pet/defs`
- `GET /api/admin/pet/defs/:petId`
- `POST /api/admin/pet/defs`
- `DELETE /api/admin/pet/defs/:petId`

职责：

- 维护龟种基础信息、稀有度、展示资源、是否启用、是否可开蛋获得、能力配置。
- 保存时做强校验并写操作日志。

### 特性模板库

- `GET /api/admin/pet/features`
- `POST /api/admin/pet/features`
- `GET /api/admin/pet/ability-options`

职责：

- 提供 featureKey 白名单。
- 提供参数 schema。
- 提供运营可直接选择的能力预设。

### 开蛋池配置

- `GET /api/admin/pet/gacha/config`
- `POST /api/admin/pet/gacha/config`
- `POST /api/admin/pet/gacha/config/reset`

配置字段：

- `enabled`
- `base_cost`
- `rarity_weights`

校验：

- 稀有度 key 合法。
- 每项概率在 `[0, 1]`。
- 概率总和等于 1。
- 概率大于 0 的稀有度必须存在可抽候选龟种。

### 紧急止血

- `POST /api/admin/pet/kill-switch`

用途：

- 禁用开蛋池。
- 禁用指定能力。
- 限制特定配置或用户范围。

请求示例：

```json
{
  "action": "disable_pool",
  "scope": "global",
  "reason": "emergency"
}
```

## 错误码

| 错误码 | 含义 |
| --- | --- |
| `ALREADY_SETTLED` | 今日已结算 |
| `EQUIP_DAILY_LIMIT` | 今日切龟次数已用尽 |
| `DEBT_UNPAID` | 欠款未还清禁止切龟 |
| `INSUFFICIENT_COINS` | 龟币余额不足 |
| `STAMINA_NOT_ENOUGH` | 体力不足 |
| `PET_NOT_OWNED` | 用户未拥有该龟种 |
| `PARAM_INVALID` | 参数错误 |
| `GACHA_POOL_DISABLED` | 开蛋池已关闭 |
| `GACHA_CONFIG_INVALID` | 开蛋配置非法 |
