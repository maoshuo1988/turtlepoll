# 配置与数据模型

## 运营配置模块

### 龟种资产库

运营维护每个龟种的基础信息：

- `petId`：不可变业务标识。
- 名称、描述、多语言文本。
- 稀有度。
- 展示资源：icon、cover、thumbnail、动效。
- 是否启用。
- 是否可通过开蛋获得。
- 能力配置 `abilities`。
- 排序权重。

### 特征库

特征库是龟种能力的配置中心：

- 能力开关：某能力是否生效。
- 能力参数：倍率、封顶、次数、阈值、取整方式。
- 互斥与依赖：如欠款补贴与存款生息互斥。
- 生效时机：每日结算、开蛋扣费、下注结算、AI 扣体力、小游戏结算等。
- 参数 schema：用于运营表单渲染和后端强校验。

### 开蛋池

- 基础费用：默认 500。
- 稀有度概率：C/B/A/S/SS/SSS。
- 稀有度内候选：默认均分，后续可扩展权重。
- 总开关：关闭后用户侧开蛋入口不可用。
- 折扣：来自当前装备龟种或未来明确的产品口径。
- 重复返还：默认按实际花费 30% 向下取整。

### 外观与装扮

- 头像框：frameId、名称、资源、是否限定、来源、解锁条件。
- 场景：sceneId、名称、资源、是否限定、来源、解锁条件。

### 风控与止血

- 能力紧急禁用：生息、补贴、火花倍率、折扣、返还等。
- 开蛋池总开关。
- 生效范围：全量、灰度、白名单。
- 阈值保护：每日封顶、最低价格、最大返还率等。

## 发布与版本快照

运营配置发布时必须生成不可变快照：

- `snapshotVersion`
- `publishedAt`
- `publishedBy`
- `petDefinitions`
- `gachaPool`
- `features`
- `rollout`

用户开蛋或结算时应解析当前生效快照，并在订单或结算记录中保存快照标识。这样可以解释历史订单、支持灰度稳定和回滚。

## 强校验

### 概率

- 稀有度 key 只允许 `C/B/A/S/SS/SSS`。
- 每项概率必须 `>= 0`。
- 概率总和必须等于 1。
- 如果某稀有度概率大于 0，则该稀有度必须至少有一只可抽取龟种。

### 价格与返还

- 基础费用必须 `>= 0`。
- 折扣后价格必须 `>= 0` 且为整数。
- 返还比例必须在 `[0, 1]`。
- 重复返还必须基于实际花费计算。

### 能力参数

- `abilities` 的 key 必须来自 FeatureCatalog 白名单。
- 每个能力参数必须符合对应 schema。
- 被禁用的 feature 不允许新增或修改挂载。
- 互斥能力不能在同一结算阶段产生冲突结果。

## 建议数据模型

### `pet_definition`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | bigint | 主键 |
| pet_id | string | 业务唯一标识，如 `basic` |
| name | json | 多语言名称 |
| rarity | string/int | 稀有度 |
| enabled | bool | 是否启用 |
| obtainable_by_egg | bool | 是否可开蛋获得 |
| display | json | 展示资源 |
| description | json | 多语言描述 |
| abilities | json | 能力配置 |
| pricing | json | 定价/折扣配置 |
| create_time | int64 | 创建时间 |
| update_time | int64 | 更新时间 |

### `user_pet`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | bigint | 主键 |
| user_id | bigint | 用户 ID |
| pet_id | bigint/string | 龟种标识 |
| level | int | 当前等级，默认 1 |
| xp | int | 当前经验 |
| obtained_at | int64 | 获得时间 |
| create_time | int64 | 创建时间 |
| update_time | int64 | 更新时间 |

### `user_pet_state`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| user_id | bigint | 用户 ID |
| equipped_pet_id | bigint/string | 当前装备龟种 |
| equipped_at | int64 | 装备时间 |
| equip_day_name | int | 北京日期，用于每日切换限制 |
| updated_at | int64 | 更新时间 |

### `pet_daily_settle_log`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | bigint | 主键 |
| user_id | bigint | 用户 ID |
| day_name | int | 北京日期 |
| balance_before | int64 | 结算前余额 |
| balance_after | int64 | 结算后余额 |
| items_json | json | 结算明细 |
| snapshot_version | string | 使用的配置快照 |
| create_time | int64 | 创建时间 |

唯一约束：`user_id + day_name`。

### `pet_gacha_order`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | bigint | 主键 |
| user_id | bigint | 用户 ID |
| order_no | string | 幂等订单号 |
| snapshot_version | string | 使用的配置快照 |
| price_base | int64 | 基础费用 |
| discount_applied | json | 命中的折扣 |
| actual_cost | int64 | 实际扣费 |
| draw_rarity | string | 抽中稀有度 |
| draw_pet_id | string | 抽中龟种 |
| is_duplicate | bool | 是否重复 |
| refund_rate | decimal | 返还比例 |
| refund_amount | int64 | 返还金额 |
| coin_log_ids | json | 扣款/返还流水引用 |
| create_time | int64 | 创建时间 |

### `pet_config_snapshot`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| snapshot_version | string | 快照版本 |
| payload | json | 完整配置快照 |
| published_by | bigint | 发布人 |
| published_at | int64 | 发布时间 |
| rollout | json | 生效策略 |
| status | string | active / rollback / disabled |

## 审计

- 所有运营变更写 `operate_log`。
- 开蛋订单保存配置快照标识。
- 每日结算日志保存结算明细和快照标识。
- 回滚和紧急开关必须记录原因。
