# 外部特性依赖详情（下）

> 本页展开金币、对赌、成就、赛季、配置相关的外部依赖接口定义、参数、策略和验收标准。  
> AI 体力、预测市场、小游戏等相关依赖详见 [09-外部特性依赖详情.md](./09-外部特性依赖详情.md)

## EXT-FRIEND-01：对赌结算通知

### 接口定义

- 接口名：`PetFriendBetService.OnFriendBetSettled()`
- 调用方向：好友对赌系统 → 宠物系统
- 调用方式：异步事件

### 输入参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `winnerId` | int64 | 是 | 获胜者用户 ID |
| `loserId` | int64 | 是 | 失败者用户 ID |
| `betId` | string | 是 | 对赌 ID |
| `betAmount` | int64 | 是 | 对赌金额 |
| `settledAt` | int64 | 是 | 结算时间戳 |

### 触发事件

- 对赌结算后调用
- 用于赛博龟窃取、海盗龟窃取、对赌加成等

### 固定策略

- **异步处理**：MQ，最多重试 3 次
- **幂等**：按 winnerId + betId 去重

## EXT-COIN-01：金币扣减接口

### 接口定义

- 接口名：`UserCoinService.Deduct()`
- 调用方向：宠物系统 → 金币系统
- 调用方式：同步 Service 方法

### 输入参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `userId` | int64 | 是 | 用户 ID |
| `amount` | int64 | 是 | 扣减金额，单位龟币 |
| `bizType` | string | 是 | 业务类型，如 `"pet_egg_hatch"` |
| `bizId` | string | 是 | 业务单据 ID，确保幂等 |
| `memo` | string | 否 | 备注描述 |

### 输出参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `success` | bool | 扣减是否成功 |
| `newBalance` | int64 | 扣减后的余额 |
| `logId` | string | 金币流水 ID |

### 错误码

| 错误码 | 触发条件 |
| --- | --- |
| `COIN_INSUFFICIENT` | 用户余额不足 |
| `DUPLICATE_BIZ_ID` | bizId 重复，已处理过 |
| `DEDUCT_FAILED` | 扣减失败 |

### 固定策略

- **幂等**：按 bizType + bizId 去重
- **超时**：500ms
- **不重试**：同步调用，失败立即返回

## EXT-ACHIEVE-01：成就解锁触发（可选）

### 接口定义

- 接口名：`AchievementService.TriggerUnlock()`
- 调用方向：宠物系统 → 成就系统
- 调用方式：异步事件或同步调用

### 输入参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `userId` | int64 | 是 | 用户 ID |
| `unlockType` | string | 是 | 解锁类型，如 `"pet_rare_frame"` |
| `achievementId` | string | 是 | 成就 ID |
| `petId` | string | 否 | 相关龟种 |

### 触发事件

- 获得稀有龟种
- 升级至特定等级
- 赛季排名达到要求

### 固定策略

- **异步处理**：可选异步，允许失败不影响主流程
- **幂等**：按 userId + achievementId 去重

| --- | --- | --- |

## EXT-CONFIG-01：灰度配置查询

### 接口定义

- 接口名：`ConfigService.IsFeatureEnabled()`
- 调用方向：宠物系统 → 配置系统
- 调用方式：同步查询

### 输入参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `userId` | int64 | 是 | 用户 ID |
| `featureKey` | string | 是 | 特性 key，如 `"pet_lucky_dice_v2"` |

### 输出参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `enabled` | bool | 是否启用 |
| `rollout` | float | 灰度比例，如 `0.5` 表示 50% 用户 |

### 固定策略

- **缓存**：按 featureKey 缓存 10 分钟
- **超时**：200ms
- **本地实现**：建议本地缓存特性配置，不频繁远程查询

## 总结

| 特性 | 调用频率 | 风险等级 | 优化建议 |
| --- | --- | --- | --- |
| 对赌通知 | 对赌结算时 | 低 | 异步 MQ |
| 金币操作 | 频繁 | 高 | 本地 Service，强幂等保证 |
| 成就解锁 | 低频 | 低 | 可选异步，允许失败 |
| 赛季排名 | 赛季结算时 | 低 | 缓存策略，避免每次都查询 |
| 灰度配置 | 视业务场景 | 低 | 强制本地缓存，减少网络 I/O |
