## EXT-AI-01：AI 体力扣减接口

### 接口定义

- 接口名：`AIStaminaService.DeductStamina()`
- 调用方向：宠物系统 → AI 系统
- 调用方式：同步 RPC 或本地 Service 方法

### 输入参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `userId` | int64 | 是 | 用户 ID |
| `abilityName` | string | 是 | 能力名，如 `"no_head_no_stamina"` 表示无头龟体力 -1 |
| `staminaCost` | int | 是 | 本次 AI 对话基础体力消耗，单位点 |
| `petId` | string | 否 | 当前装备龟种 ID，用于日志 |

### 输出参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `finalCost` | int | 实际扣减的体力值，可能因能力减免而低于 staminaCost |
| `currentStamina` | int | 扣减后的剩余体力 |
| `petAbilityApplied` | string | 应用的宠物能力名称，如 `"no_head_no_stamina"` 或空字符串 |

### 错误码

| 错误码 | 触发条件 |
| --- | --- |
| `STAMINA_INSUFFICIENT` | 当前体力不足以支持此次 AI 调用，应在调用前检查 |
| `PET_ABILITY_PARSE_ERROR` | 宠物能力配置解析失败 |
| `DEDUCT_FAILED` | 体力扣减失败，如数据库异常 |

### 固定策略

- **超时**：500ms
- **重试**：不重试（同步调用失败返回错误码）
- **熔断**：如果连续 5 次失败，熔断 30s
- **并发**：支持并发调用，通过 userId 分片确保原子性
- **限速**：无限速

### 验收标准

- 能力减免正确应用，体力扣减量符合配置
- 多次调用幂等（操作已完成，重复调用返回相同结果）
- 与体力恢复逻辑无冲突

## EXT-AI-02：AI 体力减免特性接入

### 接口定义

- 接口名：`AIStaminaService.GetPetAbilityModifier()`
- 调用方向：AI 系统 → 宠物系统
- 调用方式：同步查询

### 输入参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `userId` | int64 | 是 | 用户 ID |

### 输出参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `staminaReduction` | float | 体力消耗倍率减免，如 `0.8` 表示消耗降低到 80% |
| `abilityName` | string | 能力名，如 `"no_head_no_stamina"` |
| `petId` | string | 当前装备龟种 |

### 固定策略

- **超时**：200ms
- **缓存**：按 userId 缓存 5 分钟
- **熔断**：5 次失败熔断 20s

## EXT-MARKET-01：下注成功回调

### 接口定义

- 接口名：`PetPredictionService.OnBetPlaced()`
- 调用方向：预测市场系统 → 宠物系统
- 调用方式：异步事件或回调

### 输入参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `userId` | int64 | 是 | 用户 ID |
| `betAmount` | int64 | 是 | 下注金额 |
| `marketId` | string | 是 | 市场 ID |
| `timestamp` | int64 | 是 | 下注时间戳（北京时间） |

### 触发事件

- 用户成功下注后调用
- 用于检查财神龟"每日首次下注加成"

### 固定策略

- **异步处理**：MQ 或消息队列，不阻塞下注流程
- **重试**：最多重试 3 次，指数退避 1s/2s/4s
- **超时**：单次处理 5s

## EXT-MARKET-02：市场结算时获胜通知

### 接口定义

- 接口名：`PetPredictionService.OnMarketResolved()`
- 调用方向：预测市场系统 → 宠物系统
- 调用方式：异步事件

### 输入参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `userId` | int64 | 是 | 用户 ID |
| `marketId` | string | 是 | 市场 ID |
| `isWin` | bool | 是 | 用户是否获胜 |
| `winAmount` | int64 | 否 | 获胜奖励（可选） |
| `actualOdds` | float | 否 | 实际赔率 |
| `resolvedAt` | int64 | 是 | 结算时间戳 |

### 触发事件

- 市场结算后调用
- 用于猎人龟爆冷奖励、鬼龟手续费减免等

### 固定策略

- **异步处理**：MQ，最多重试 3 次
- **幂等**：按 userId + marketId 去重，同一市场只结算一次

## EXT-GAME-01：小游戏得分上报

### 接口定义

- 接口名：`PetGameService.OnGameScoreReported()`
- 调用方向：小游戏系统 → 宠物系统
- 调用方式：异步事件或同步回调

### 输入参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `userId` | int64 | 是 | 用户 ID |
| `gameId` | string | 是 | 游戏类型标识 |
| `score` | int | 是 | 本局得分 |
| `reward` | int64 | 是 | 基础奖励龟币 |
| `playedAt` | int64 | 是 | 游戏时间（北京时间） |

### 输出参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `finalReward` | int64 | 加成后的最终奖励 |
| `bonusRatio` | float | 加成倍率，如 `1.2` 表示 +20% |
| `abilityApplied` | string | 应用的宠物能力名 |

### 固定策略

- **幂等**：按 userId + gameId + playedAt 去重
- **每日上限**：同一用户同一日期"第一局龟币奖励"最多触发一次
- **超时**：1s

---
