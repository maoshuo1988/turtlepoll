# 宠物特性清单总览

> 本页按当前代码落地情况重排。  
> “已实现”表示已有可调用接口或后端结算链路；“未实现”表示只有设计口径、配置种子、占位接口，或未接入真实业务执行。

## 已实现

| 分类 | 特性 | 状态 | 优先级 | 详情 |
| --- | --- | --- | --- | --- |
| 用户侧资产 | 当前装备龟种查询 | 已实现 | P0 | 已有 `GET /api/pet/equip`，返回当前装备、能力 JSON、能力说明、图片和等级等字段 |
| 用户侧资产 | 用户拥有龟种列表 | 已实现 | P0 | 已有 `GET /api/pet/owned`，返回用户拥有的龟种、等级、经验和是否当前装备 |
| 注册初始化 | 小龟注册赠送 | 已实现 | P0 | 注册后授予 `basic` 小龟，并由小龟 `signup_bonus` 特性发放 500 龟币 |
| 注册初始化 | 新用户默认装备小龟 | 已实现 | P0 | 注册事务内创建 `UserPet` 和 `UserPetState`，默认装备 `basic` 小龟 |
| 装备规则 | 切换龟种 | 已实现 | P0 | 已有 `POST /api/pet/equip`；校验用户是否拥有目标龟种 |
| 装备规则 | 每日切换限制 | 已实现 | P0 | `UserPetService.EquipPet` 按北京时间 `EquipDayName` 限制每日一次，错误码 `EQUIP_DAILY_LIMIT` |
| 余额能力 | 欠款锁龟 | 已实现 | P0 | 切龟前读取金币余额，余额 < 0 返回 `DEBT_UNPAID` |
| 每日结算 | 登录基础奖励 | 已实现 | P0 | `PetDailySettleService.SettleOnLogin` 已发放 `base_checkin=100` 并写每日结算日志 |
| 每日结算 | 每日结算幂等 | 已实现 | P0 | `pet_daily_settle_log` 按 `userId + dayName` 读取和写入，同日重复登录返回 cached summary |
| 每日结算 | 火花基础奖励 | 已实现 | P0 | `PetSparkService.ComputeSparkRaw` 已接入每日登录结算，按连续登录天数计算火花奖励 |
| 每日结算 | 每日登录加成 `signin_bonus` 新链路 | 已实现 | P0 | 登录结算主链路读取当前装备龟种 `signin_bonus` 并发放 `pet_signin_bonus` |
| 每日结算 | 火花倍率加成 | 已实现 | P0 | 装备龟种配置 `spark_multiplier` 且 FeatureCatalog 启用时，结算额外发放 `spark_bonus` |
| 余额能力 | 欠款补贴 | 已实现 | P0 | 装备龟种配置 `debt_subsidy` 且余额 < 0 时，每日结算发放补贴 |
| 余额能力 | 存款生息 | 已实现 | P0 | 装备龟种配置 `deposit_interest` 且余额 > 0 时，每日结算发放生息 |
| 运营配置 | FeatureCatalog 种子 | 已实现 | P0 | 已内置 `signin_bonus`、`spark_multiplier`、`debt`、`debt_subsidy`、`deposit_interest`、`first_bet_bonus` 特性模板 |
| 运营配置 | 龟种定义维护 | 已实现 | P0 | 已有管理端 `GET/POST /api/admin/pet/defs` 等龟种定义维护接口 |
| 运营配置 | 龟种能力挂载 | 已实现 | P0 | 已有 `PetAbilityService` 支持替换、新增、删除龟种 `abilities`，并校验 FeatureCatalog |
| 运营配置 | 能力预设列表 | 已实现 | P0 | 已有 `GET /api/admin/pet/ability-options`，返回登录加成、火花、补贴、生息等能力预设 |
| 开蛋 | 开蛋池配置 | 已实现 | P1 | 已有 `PetGachaService` 和管理端配置接口，支持启用、基础费用、稀有度概率配置与概率和校验 |
| 开蛋 | 基础开蛋 | 已实现 | P1 | 已有 `POST /api/pet/egg/hatch`，按开蛋池稀有度概率抽取可开蛋龟种并扣费 |
| 开蛋 | 重复龟种返还 | 已实现 | P1 | 开蛋抽中已拥有龟种时，按当前实际扣费 30% 返还并写金币流水 |
| AI 与体力 | 独立 AI 体力模型 | 已实现 | P1 | 已有 `/api/ai/stamina` 与苹果恢复逻辑，体力和龟币扣减在 AI 领域已落地 |
| 用户侧展示 | 宠物状态接口占位 | 已实现占位 | P2 | 已有 `GET /api/pet/status` 返回空结构，未接入真实心情/状态计算 |
| 体力系统 | 宠物体力接口占位 | 已实现占位 | P2 | 已有 `GET /api/pet/stamina` 固定返回 100/100/每小时 5，未接入宠物领域真实体力数据 |

## 功能影响速查

| 功能模块 | 会被哪些特性影响 | 备注 |
| --- | --- | --- |
| 注册 | 小龟注册赠送 | 注册服务只触发宠物初始化；金币由小龟能力发放 |
| 每日登录 & 签到 | 登录加成、火花倍率、幸运骰、欠款补贴、存款生息 | 统一北京时间日切与幂等 |
| 开蛋系统 | 开蛋折扣、重复返还 | 返还按实际花费计算 |
| AI 对话 | 体力消耗减免、心情系统 | 体力不足不调用 LLM |
| 体力系统 | 体力消耗减免、龟粮折扣 | 需和苹果售价口径统一 |
| 小游戏联动 | 护盾、体积缩小、收益加成 | 需明确取整顺序和每日第一局奖励幂等 |
| 投票下注 | 手续费减免、首次下注奖励、爆冷奖励 | 需统一胜率口径、取整和上限 |
| 好友 & 私人对赌 | 对赌胜利奖励、窃取 | 需要处理余额不足与取整 |
| 赛季系统 | 赛季排名提升 | 需明确排序落点 |
| 龟种切换 | 欠账未还清禁止切换、每日切换限制 | 错误码：`DEBT_UNPAID` / `EQUIP_DAILY_LIMIT` |
