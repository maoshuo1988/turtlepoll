# 初始化数据说明

> 本页说明 AI 系统上线时的初始化数据、种子数据和运营配置。

## 1. 初始化阶段

### 1.1 阶段 1：数据库表结构初始化

**时间点**：系统上线前的迁移脚本运行  
**责任人**：技术  
**验收**：表结构创建完成，索引建立

#### 表列表

- `user_ai_stamina`：用户体力记录
- `ai_message`：AI 消息历史（聊天和推送）
- `user_ai_memory`：用户 AI 记忆
- `ai_message_template`：推送模板库
- `template_user_view`：模板曝光记录
- `ai_stamina_log`：体力变更流水
- `ai_presence`：用户在线状态

#### 关键约束

```sql
-- ai_message 防重
ALTER TABLE ai_message 
ADD UNIQUE KEY uk_request_id (request_id);

-- template_user_view 复合主键
ALTER TABLE template_user_view 
ADD UNIQUE KEY uk_user_template (user_id, template_id);

-- ai_presence 时间戳索引
ALTER TABLE ai_presence 
ADD KEY idx_last_ai_interact (last_ai_interact_at);
```

## 2. 数据迁移脚本

### 2.1 迁移脚本命名规范

```
000XXX_migration_script_ai_[功能]_init.go
000XXX_migration_script_ai_[表名]_add_[字段].go
```

### 2.2 脚本模板（Go + GORM）

```go
// 文件：migrations/000XXX_migration_script_ai_table_init.go

package migrations

import (
  "fmt"
  "github.com/pkg/errors"
)

func MigrateAITableInit(db interface{}) error {
  // 1. 创建表
  type UserAIStamina struct {
    ID            int64     `gorm:"primaryKey"`
    UserId        int64     `gorm:"uniqueIndex"`
    Stamina       int       
    MaxStamina    int       `gorm:"default:100"`
    LastRecoverAt time.Time
    CreatedAt     time.Time
    UpdatedAt     time.Time
  }

  if err := db.(*gorm.DB).AutoMigrate(&UserAIStamina{}); err != nil {
    return errors.Wrap(err, "failed to migrate UserAIStamina")
  }

  // 2. 添加索引
  if err := db.(*gorm.DB).Model(&UserAIStamina{}).
    AddIndex("idx_last_recover", "last_recover_at").Error; err != nil {
    return errors.Wrap(err, "failed to add index")
  }

  return nil
}
```

### 2.3 模板初始化脚本

```go
func MigrateAITemplatesSeed(db interface{}) error {
  templates := []AIMessageTemplate{
    {TemplateKey: "settle_win_1", Scene: "settle_push", Content: "赢了呢!{amount}龟币入账", ...},
    // ... 更多模板
  }

  for _, t := range templates {
    // 检查是否已存在（幂等）
    var count int64
    db.(*gorm.DB).Model(&AIMessageTemplate{}).
      Where("template_key = ?", t.TemplateKey).
      Count(&count)
    
    if count == 0 {
      if err := db.(*gorm.DB).Create(&t).Error; err != nil {
        return errors.Wrap(err, "failed to seed template")
      }
    }
  }

  return nil
}
```

## 3. 每日初始化任务

### 3.1 用户体力每日重置（可选）

如需每日重置体力上限，则在每日 0 点执行：

```sql
UPDATE user_ai_stamina 
SET stamina = max_stamina, 
    daily_used_count = 0 
WHERE DATE(CONVERT_TZ(created_at, '+00:00', '+08:00')) = CURDATE();
```

当前设计不做强制每日重置，只按自然恢复懒结算。

### 3.2 模板曝光统计重置（可选）

如需按周期重置曝光计数，在每周一 0 点：

```sql
DELETE FROM template_user_view 
WHERE WEEK(created_at) < WEEK(NOW());
```

当前设计不做重置，持续积累。

## 6. 故障回滚

### 6.1 禁用 AI 聊天

```
POST /api/admin/ai/kill-switch
{
  "key": "ai_chat_enabled",
  "enabled": false,
  "reason": "DeepSeek 故障"
}
```

用户调用聊天接口时，返回兜底文案，不调用 DeepSeek。

### 6.2 禁用 AI 推送

```
POST /api/admin/ai/kill-switch
{
  "key": "ai_push_enabled",
  "enabled": false
}
```

结算、闲置事件不生成推送消息。

### 6.3 数据恢复

- 表数据回滚：使用 binlog 恢复到指定时间点
- 模板恢复：保留种子模板版本快照，支持回滚
- 配置恢复：保留历史配置版本，支持版本切换
