# AI 聊天特性清单

> 本文按优先级整理 AI 聊天需要实现的特性。

## 1. MVP 特性

| 特性 | 描述 | 触发方式 | 调用 LLM | 优先级 |
| --- | --- | --- | --- | --- |
| 用户主动 AI 对话 | 用户向小龟提问，支持闲聊、比赛分析、身份问答 | 用户发送消息 | 是 | P0 |
| 体力校验 | 主动对话前检查体力，不足直接兜底 | 用户发送消息 | 否 | P0 |
| AI 身份兜底 | 问模型身份时回答“小龟”身份 | 用户发送消息 | 可不调 | P0 |
| 投票结算赢/输推送 | 结算后推送结果文案 | 后端结算事件 | 否 | P0 |
| 连胜推送 | 当前连胜达到 3 场及以上 | 后端结算事件 | 否 | P0 |
| 连败推送 | 当前连败达到 5 场及以上 | 后端结算事件 | 否 | P0 |
| 模板池随机 | 主动推送从模板池选文案并替换占位符 | 后端推送服务 | 否 | P0 |
| 对话消息保存 | 保存用户消息和小龟回复 | 聊天/推送 | 否 | P0 |
| DeepSeek 调用封装 | 服务端统一封装非流式调用 | 主动聊天 | 是 | P0 |

## 2. P1 特性

| 特性 | 描述 | 触发方式 | 调用 LLM | 优先级 |
| --- | --- | --- | --- | --- |
| 用户主动问记忆 | 用户问最大盈利、首次开蛋、最长连胜等 | 用户发送消息 | 是 | P1 |
| 记忆 Flag 维护 | 业务事件更新关键记忆 | 结算/开蛋/登录 | 否 | P1 |
| 闲置记忆推送 | 用户停留且未互动时推送记忆文案 | 在线状态判断 | 否 | P1 |
| 模板去重 | 优先选择未见过或见过最少的模板 | 主动推送 | 否 | P1 |
| 敏感话题兜底 | 不直接预测敏感话题，引导到站内预测热度 | 用户发送消息 | 可不调 | P1 |
| 用户辱骂兜底 | 返回克制短文案 | 用户发送消息 | 可不调 | P1 |
| token usage 记录 | 记录模型、耗时、token 消耗 | DeepSeek 响应后 | 否 | P1 |
| 用户频控 | 限制每日主动聊天次数 | 用户发送消息 | 否 | P1 |

## 3. 后续迭代

| 特性 | 描述 | 备注 |
| --- | --- | --- |
| 流式输出 | AI 回复逐字或分段展示 | 先做非流式，稳定后接。 |
| Tool Calls | 让模型请求查询市场、余额、赛事状态 | 需要严格服务端白名单。 |
| 后台模板管理 | 运营配置模板启停、权重、场景 | P1 稳定后做。 |
| 异步 AI 补充模板池 | 定时生成新文案入库 | 不影响实时推送。 |
| 装备龟语气调味 | 不同龟种影响聊天语气 | 需要 28 只龟 personality 设计。 |
| 生日/节日/里程碑推送 | 运营类主动消息 | 依赖更多用户字段和活动口径。 |

## 4. DeepSeek 调用策略

| 场景 | 是否调用 DeepSeek | 模型 | thinking | 说明 |
| --- | --- | --- | --- | --- |
| 普通闲聊 | 是 | `deepseek-v4-flash` | disabled | 默认低成本模型。 |
| AI 身份问答 | 可不调用 | 无 | 无 | 推荐规则兜底。 |
| 比赛/预测简单分析 | 是 | `deepseek-v4-flash` | disabled | 基于站内上下文生成简短分析。 |
| 复杂预测分析 | 是 | `deepseek-v4-pro` | enabled | 可使用 `reasoning_effort=high`。 |
| 用户主动问记忆 | 是 | `deepseek-v4-flash` | disabled | 事实由后端提供。 |
| 投票结算推送 | 否 | 无 | 无 | 只走模板。 |
| 闲置记忆推送 | 否 | 无 | 无 | 只走模板。 |
| 体力不足 | 否 | 无 | 无 | 系统兜底。 |
| DeepSeek 不可用 | 否 | 无 | 无 | 系统降级文案。 |

## 5. 记忆 Flag

| Flag | 触发时机 | 用途 |
| --- | --- | --- |
| `first_egg_turtle` | 用户第一次开蛋获得龟种 | 闲置推送 / 用户问 |
| `first_sss` | 第一次抽到龟壳或 SSS | 用户问 |
| `biggest_win_amount` | 单场盈利刷新最大值 | 闲置推送 / 用户问 |
| `biggest_win_event` | 单场盈利刷新最大值 | 配合最大盈利金额 |
| `longest_win_streak` | 连胜纪录刷新 | 闲置推送 / 用户问 |
| `longest_lose_streak` | 连败纪录刷新 | 用户问 |
| `current_login_streak` | 每日登录结算 | 用户问 |
| `total_dialogue_count` | 主动对话成功后 | 用户问 |
| `total_turtles_owned` | 获得龟种后 | 用户问 |
| `vote_win_streak` | 投票结算赢时更新 | 连胜推送 |
| `vote_lose_streak` | 投票结算输时更新 | 连败推送 |

## 6. 验收重点

1. 体力不足时不调用 DeepSeek。
2. 主动推送不消耗体力。
3. 主动推送不实时调用 DeepSeek。
4. 普通分析不会主动提起历史记忆。
5. 问模型身份不会暴露底层模型。
6. DeepSeek 调用失败不扣体力。
7. 模板去重能避免同一用户短期反复看到同一句。
