# 06-接口补充（管理侧与内部触发）

> 本文件是 06 的补充文档，专门定义管理接口与内部事件契约。

## 1. 管理侧接口

### 1.1 运营赠送体力

- 方法：`POST`
- URL：`/api/admin/coin/ai_stamina/grant`
- 鉴权：管理员

请求：

```json
{
  "userId": 1001,
  "amount": 3,
  "reason": "运营补偿"
}
```

响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "userId": 1001,
    "granted": 3,
    "current": 8
  }
}
```

固定策略：

- `amount` 必须大于 0。
- 必须记录操作日志（操作者、原因、时间、变更值）。

### 1.2 配置查询与热重载

- `GET /api/admin/ai/config`：查询当前 AI 配置
- `POST /api/admin/ai/config/reload`：触发配置热重载

重载请求：

```json
{
  "configType": "ai_config",
  "version": "v1.20260611"
}
```

固定策略：

- 热重载超时：1 秒。
- 重载失败时保留旧配置继续服务。

### 1.3 止血开关管理

- 方法：`POST`
- URL：`/api/admin/ai/kill-switch`

请求：

```json
{
  "key": "ai_chat_enabled",
  "enabled": false,
  "reason": "DeepSeek 故障中"
}
```

固定策略：

- 支持键：`ai_chat_enabled`、`ai_push_enabled`、`ai_stamina_enabled`、`apple_purchase_enabled`。
- 生效方式：配置更新成功后立即生效，无需重启。

## 2. 内部触发契约

### 2.1 结算事件触发（站内）

- 接口名：`OnSettlement(event SettlementEvent)`
- 调用方向：结算模块 -> AI 推送模块
- 调用方式：进程内服务调用

输入字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `requestId` | string | 是 | 幂等请求标识 |
| `userId` | int64 | 是 | 用户 ID |
| `bizType` | string | 是 | 业务类型（如 `predict_market`） |
| `bizId` | int64 | 是 | 业务主键 |
| `scene` | string | 是 | `win` / `lose` |
| `amount` | int64 | 是 | 结算变动金额 |
| `settledAt` | int64 | 是 | 结算时间戳 |

固定策略：

- 幂等键：`(user_id, request_id)` 唯一索引。
- 同一 `requestId` 重复调用必须只生效一次。
- 命中 `lose_streak >= 5` 或 `win_streak >= 3` 时优先使用 streak 场景。

### 2.2 闲置扫描触发（站内）

- 接口名：`RunIdleScan(now int64)`
- 调用方向：定时任务 -> AI 推送模块
- 调用方式：cron

固定策略：

- 扫描周期：每 1 分钟执行一次。
- 闲置阈值：`idleTriggerMinutes = 10`。
- 冷却窗口：`idlePushCooldownMinutes = 120`。
- 日上限：`idlePushDailyLimit = 2`。

## 3. Iris MVC 路由绑定清单

当 URL 包含短横线或多级路径时，必须显式绑定。

```go
import "github.com/kataras/iris/v12/mvc"

func (c *AIController) BeforeActivation(b mvc.BeforeActivation) {
    b.Handle("POST", "/stamina/apple", "PostStamina_apple")
    b.Handle("GET", "/pushes/unread", "GetPushes_unread")
    b.Handle("POST", "/pushes/read", "PostPushes_read")
    b.Handle("GET", "/pushes/stream", "GetPushes_stream")
}
```

```go
import "github.com/kataras/iris/v12/mvc"

func (c *AIAdminController) BeforeActivation(b mvc.BeforeActivation) {
    b.Handle("POST", "/coin/ai_stamina/grant", "PostCoinAiStaminaGrant")
}
```

## 4. 验收清单

1. 文档 URL 与实际路由一致。
2. 使用文档 URL 做 curl 验证可命中后端。
3. `/api/admin/**` 同时验证 Cookie 与 Bearer 两种鉴权。
4. SSE 离线时可通过未读接口补拉推送。
5. 结算事件重复重放时不生成重复推送。
