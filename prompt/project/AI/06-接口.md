# AI 系统接口

> 本文定义 AI 模块的对外接口契约，包含用户侧与管理侧。

## 1. 用户侧接口

### 1.1 发送聊天消息

- 方法：`POST`
- URL：`/api/ai/chat`

请求：

```json
{
  "message": "帮我看看这场曼城对阿森纳应该买哪边",
  "contextType": "predict_market",
  "contextId": 123
}
```

返回：

```json
{
  "messageId": 10001,
  "message": "这场比较微妙呀...",
  "scene": "chat",
  "staminaCost": 1,
  "staminaLeft": 4,
  "model": "deepseek-v4-flash"
}
```

### 1.2 查询聊天历史

- 方法：`GET`
- URL：`/api/ai/messages?page=1&pageSize=20`

### 1.3 上报在线状态

- 方法：`POST`
- URL：`/api/ai/presence`

请求：

```json
{
  "page": "vote",
  "active": true
}
```

### 1.4 拉取未读推送

- 方法：`GET`
- URL：`/api/ai/pushes/unread`

### 1.5 标记推送已读

- 方法：`POST`
- URL：`/api/ai/pushes/read`

请求：

```json
{
  "ids": [20001, 20002]
}
```

### 1.6 SSE 推送通道

- 方法：`GET`
- URL：`/api/ai/pushes/stream`
- 协议：SSE

事件示例：

```text
id: 20001
event: ai_push
data: {"id":20001,"scene":"win","content":"这把赢了 120。小龟先替你把尾巴翘一下。","contextType":"predict_market","contextId":123,"createTime":1760000000}
```

### 1.7 查询 AI 体力

- 方法：`GET`
- URL：`/api/ai/stamina`

### 1.8 苹果恢复体力

- 方法：`POST`
- URL：`/api/ai/stamina/apple`

请求：

```json
{
  "count": 1
}
```

## 2. 管理侧接口

### 2.1 运营赠送体力

- 方法：`POST`
- URL：`/api/admin/coin/ai_stamina/grant`

### 2.2 模板管理（规划）

- `GET /api/admin/ai/templates`
- `POST /api/admin/ai/templates`
- `POST /api/admin/ai/templates/{id}/enable`

### 2.3 配置热重载（规划）

- `POST /api/admin/ai/config/reload`

## 3. 错误码

| 错误码 | 场景 | 说明 |
| --- | --- | --- |
| `AI_DISABLED` | 功能关闭 | AI 功能未开启 |
| `AI_STAMINA_NOT_ENOUGH` | 体力不足 | 返回兜底文案，不调用 LLM |
| `AI_INPUT_TOO_LONG` | 输入过长 | 超过长度限制 |
| `AI_RATE_LIMITED` | 用户频控 | 超过每日消息上限 |
| `AI_PROVIDER_UNAVAILABLE` | 模型不可用 | DeepSeek 不可用或超时 |
| `AI_MEMORY_NOT_FOUND` | 记忆缺失 | 没有可用 Flag 事实 |

## 4. Iris MVC 路由防错

当 URL 含短横线或多级路径时，必须使用 `BeforeActivation` 显式绑定。

示例：

```go
import "github.com/kataras/iris/v12/mvc"

func (c *AIController) BeforeActivation(b mvc.BeforeActivation) {
    b.Handle("GET", "/pushes/stream", "GetPushes_stream")
    b.Handle("POST", "/stamina/apple", "PostStamina_apple")
}
```

验证要求：

1. 新增接口必须按文档 URL 用 curl 验证。
2. 返回 HTML 首页通常表示路由未命中。
3. `/api/admin/**` 同时验证 `bbsgo_token` 或 `Authorization: Bearer <token>`。
