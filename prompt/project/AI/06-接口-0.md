# AI 系统接口

> 本文是 06 编号主文档，只定义 AI 模块接口契约。Prompt 与模板内容不再放在 06。

## 1. 通用约定

- 鉴权：`/api/ai/**` 需登录；`/api/admin/**` 需管理员权限。
- 响应格式：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

- 时间字段统一为 Unix 秒级时间戳。
- 体力消耗规则：主动对话每次固定消耗 1 点体力。
- 内容类型：请求和响应均为 `application/json`（SSE 接口除外）。

## 2. 用户侧接口

### 2.1 发送聊天消息

- 方法：`POST`
- URL：`/api/ai/chat`
- 说明：用户主动对话入口。

请求：

```json
{
  "message": "帮我看看这场曼城对阿森纳应该买哪边",
  "contextType": "predict_market",
  "contextId": 123
}
```

`contextType` 取值约束：

- `predict_market`（MVP 必选）
- `match_schedule`
- `pk_topic`
- `battle`

响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "messageId": 10001,
    "scene": "chat",
    "content": "这场比较微妙，我更倾向主队不败。",
    "staminaCost": 1,
    "staminaLeft": 4,
    "model": "deepseek-v4-flash"
  }
}
```

固定策略：

- 模型超时：30 秒。
- 失败重试：最多 3 次。
- 重试失败：返回兜底文案并记录错误日志。
- DeepSeek 调用失败时 `staminaCost=0`。
- 仅在 DeepSeek 成功并保存回复后扣减体力。

### 2.2 查询聊天历史

- 方法：`GET`
- URL：`/api/ai/messages?page=1&pageSize=20`

响应 `data`：

```json
{
  "list": [
    {
      "id": 10001,
      "scene": "chat",
      "content": "这场比较微妙，我更倾向主队不败。",
      "status": 1,
      "createTime": 1760000000
    }
  ],
  "total": 1
}
```

### 2.3 查询体力

- 方法：`GET`
- URL：`/api/ai/stamina`

响应 `data`：

```json
{
  "current": 4,
  "max": 10,
  "applePrice": 5,
  "nextRecoverAt": 1760003600,
  "dailyUsedCount": 2,
  "dailyLimit": 50
}
```

### 2.4 苹果恢复体力

- 方法：`POST`
- URL：`/api/ai/stamina/apple`

请求：

```json
{
  "count": 1
}
```

响应 `data`：

```json
{
  "current": 5,
  "coinCost": 5
}
```

固定策略：

- 价格固定：每点体力 5 龟币。
- `count` 必须大于 0。
- 体力已满时返回业务错误，不扣龟币。
- 扣龟币与加体力必须在同一事务内。

### 2.5 Presence 上报

- 方法：`POST`
- URL：`/api/ai/presence`

请求：

```json
{
  "page": "vote",
  "active": true
}
```

响应 `data`：

```json
{
  "active": true,
  "lastSeenAt": 1760000000
}
```

固定策略：

- 前端心跳周期：60 秒。
- 在线判定窗口：`last_seen_at` 在 60 秒内。

### 2.6 拉取未读推送

- 方法：`GET`
- URL：`/api/ai/pushes/unread`

响应 `data`：

```json
{
  "list": [
    {
      "id": 20001,
      "scene": "win",
      "content": "这把赢了 120。小龟先替你把尾巴翘一下。",
      "contextType": "predict_market",
      "contextId": 123,
      "createTime": 1760000000
    }
  ]
}
```

### 2.7 标记推送已读

- 方法：`POST`
- URL：`/api/ai/pushes/read`

请求：

```json
{
  "ids": [20001, 20002]
}
```

响应 `data`：

```json
{
  "updated": 2
}
```

固定策略：

- 仅允许更新当前用户自己的消息。
- 重复提交同一 ID 集合必须幂等。

### 2.8 SSE 推送通道

- 方法：`GET`
- URL：`/api/ai/pushes/stream`
- 协议：SSE

事件：

```text
id: 20001
event: ai_push
data: {"id":20001,"scene":"win","content":"这把赢了 120。小龟先替你把尾巴翘一下。","contextType":"predict_market","contextId":123,"createTime":1760000000}
```

固定策略：

- SSE 在线时实时投递。
- SSE 离线时前端通过未读接口补拉。

## 3. 错误码

| 错误码 | HTTP 状态 | 触发条件 |
| --- | --- | --- |
| `AI_DISABLED` | 403 | AI 功能开关关闭 |
| `AI_INPUT_TOO_LONG` | 400 | 输入超过上限 |
| `AI_RATE_LIMITED` | 429 | 触发用户频控 |
| `AI_STAMINA_NOT_ENOUGH` | 425 | 体力不足 |
| `AI_COIN_NOT_ENOUGH` | 400 | 购买体力时余额不足 |
| `AI_PROVIDER_TIMEOUT` | 504 | 模型调用超时 |
| `AI_PROVIDER_UNAVAILABLE` | 503 | 模型服务不可用 |
| `AI_PROVIDER_RATE_LIMITED` | 429 | 模型服务限流 |
| `AI_INVALID_PARAMS` | 400 | 参数缺失或格式错误 |
| `AI_NO_PERMISSION` | 403 | 无访问权限 |

## 4. 实现防错（Iris MVC）

当 URL 包含短横线或多级路径时，必须在 `BeforeActivation` 显式绑定路由。

```go
import "github.com/kataras/iris/v12/mvc"

func (c *AIController) BeforeActivation(b mvc.BeforeActivation) {
    b.Handle("GET", "/pushes/stream", "GetPushes_stream")
    b.Handle("POST", "/stamina/apple", "PostStamina_apple")
}
```

本地验证要求：

1. 所有新增接口都要按文档 URL 做 curl 验证。
2. 返回 HTML 首页视为路由未命中。
3. `/api/admin/**` 同时验证 Cookie `bbsgo_token` 与 `Authorization: Bearer <token>` 两种鉴权方式。
