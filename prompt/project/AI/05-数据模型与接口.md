# AI 聊天数据模型与接口草案

> 本文是设计草案。真实接口需要等代码落地后再写入 `docs/api`。

## 1. 数据模型草案

### 1.1 AI 消息

```text
ai_message
  id
  user_id
  role              user / assistant / system
  scene             chat / memory_qa / settle_push / idle_push / fallback
  content
  model
  prompt_tokens
  completion_tokens
  total_tokens
  stamina_cost
  context_type
  context_id
  request_id
  created_at
```

用途：

- 展示聊天历史。
- 记录主动推送。
- 排查 DeepSeek 调用。
- 统计成本和体力消耗。

不保存：

- API Key。
- Authorization Header。
- DeepSeek `reasoning_content`。

### 1.2 用户 AI 记忆

```text
user_ai_memory
  id
  user_id
  flag_key
  flag_value
  flag_meta
  updated_at
  created_at
```

说明：

- `flag_key`：如 `biggest_win_amount`。
- `flag_value`：简单值，如 `1200`。
- `flag_meta`：JSON 字符串，存事件名、联赛、时间等扩展信息。

### 1.3 推送模板

```text
dialogue_template
  id
  scene
  content
  enabled
  weight
  created_at
  updated_at
```

### 1.4 用户模板曝光

```text
template_user_view
  id
  user_id
  template_id
  view_count
  last_viewed_at
```

选择策略：

1. 优先选用户未见过的模板。
2. 都见过时选 `view_count` 最少的模板。
3. 次数相同再按权重或随机。

### 1.5 用户在线状态

```text
user_ai_presence
  user_id
  page
  active
  first_seen_at
  last_seen_at
  last_ai_interact_at
  last_idle_push_at
  idle_push_count_date
  idle_push_count
```

用途：

- 判断用户是否在 App 内停留。
- 判断是否达到闲置推送条件。
- 控制冷却期和每日上限。

## 2. 接口草案

### 2.1 发送聊天消息

```text
POST /api/ai/chat
```

请求：

```json
{
  "message": "帮我看看这场曼城对阿森纳应该买哪边",
  "contextType": "predict_market",
  "contextId": 123
}
```

返回：

```json
{
  "messageId": 10001,
  "message": "这场比较微妙呀...",
  "scene": "chat",
  "staminaCost": 1,
  "staminaLeft": 4,
  "model": "deepseek-v4-flash"
}
```

### 2.2 查询聊天历史

```text
GET /api/ai/messages?page=1&pageSize=20
```

返回：

```json
{
  "results": [
    {
      "id": 10001,
      "role": "assistant",
      "scene": "chat",
      "content": "这场比较微妙呀...",
      "createdAt": 1760000000
    }
  ],
  "page": 1,
  "pageSize": 20,
  "total": 1
}
```

### 2.3 上报在线状态

```text
POST /api/ai/presence
```

请求：

```json
{
  "page": "vote",
  "active": true
}
```

返回：

```json
{
  "ok": true
}
```

### 2.4 拉取未读 AI 推送

如果没有 WebSocket，可先用轮询。

```text
GET /api/ai/pushes/unread
```

返回：

```json
{
  "results": [
    {
      "id": 20001,
      "scene": "idle_biggest_win",
      "content": "翻了下你的战绩,最大那次 1200 还在两个月前。",
      "createdAt": 1760000000
    }
  ]
}
```

### 2.5 标记推送已读

```text
POST /api/ai/pushes/read
```

请求：

```json
{
  "ids": [20001, 20002]
}
```

## 3. 错误码

| 错误码 | 场景 | 处理 |
| --- | --- | --- |
| `AI_DISABLED` | AI 功能未开启 | 返回功能关闭文案。 |
| `AI_STAMINA_NOT_ENOUGH` | 体力不足 | 返回“小龟睡着啦”兜底。 |
| `AI_INPUT_TOO_LONG` | 输入过长 | 提醒用户缩短问题。 |
| `AI_RATE_LIMITED` | 用户触发频控 | 提醒稍后再试。 |
| `AI_PROVIDER_UNAVAILABLE` | DeepSeek 不可用 | 返回系统兜底，不扣体力。 |
| `AI_MEMORY_NOT_FOUND` | 记忆事实不存在 | 走温和兜底。 |

## 4. 服务职责

```text
internal/services/ai/
  ai_chat_service.go
  ai_memory_service.go
  ai_template_service.go
  ai_push_service.go
  ai_risk_service.go
  deepseek_client.go
```

| 服务 | 职责 |
| --- | --- |
| `AIChatService` | 用户主动聊天、体力校验、LLM 调用、对话次数累计 |
| `AIMemoryService` | Flag 读写、记忆问答上下文拼装 |
| `AITemplateService` | 模板选择、占位符替换、曝光记录 |
| `AIPushService` | 投票结算推送、闲置推送、冷却和频率控制 |
| `AIRiskService` | 输入长度、敏感、辱骂、频控 |
| `DeepSeekClient` | DeepSeek API 调用封装 |

## 5. 事件接入点

| 业务事件 | AI 处理 |
| --- | --- |
| 投票结算完成 | 更新 win/lose streak，触发结算推送。 |
| 单场盈利刷新最大值 | 更新 `biggest_win_amount` / `biggest_win_event`。 |
| 用户第一次开蛋 | 更新 `first_egg_turtle`。 |
| 抽到 SSS | 更新 `first_sss`。 |
| 登录结算 | 更新 `current_login_streak`。 |
| 获得新龟种 | 更新 `total_turtles_owned`。 |
| 用户主动聊天成功 | 更新 `total_dialogue_count`。 |
