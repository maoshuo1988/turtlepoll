# AI 系统配置与数据模型

> 本文描述 AI 模块的配置项、核心数据表和约束关系。

## 1. 核心配置

### 1.1 AI 聊天配置

```yaml
aiChat:
  enabled: true
  maxInputChars: 1000
  maxHistoryMessages: 12
  defaultStaminaCost: 1
  dailyUserMessageLimit: 100
```

### 1.2 体力配置

```yaml
aiStamina:
  maxStamina: 100
  staminaRecoverMinutes: 60
  staminaRecoverPerUnit: 1
  appleCostInCoin: 5
  appleRecoveryPerApple: 1
```

### 1.3 推送配置

```yaml
aiPush:
  settlementEnabled: true
  idleEnabled: true
  idleTriggerMinutes: 10
  idlePushCooldownMinutes: 60
  idlePushDailyLimit: 2
```

## 2. 核心数据模型

### 2.1 ai_message

```text
ai_message
  id
  user_id
  role              user / assistant / system
  scene             chat / memory_qa / settle_push / idle_push / fallback
  content
  model
  prompt_tokens
  completion_tokens
  total_tokens
  stamina_cost
  context_type
  context_id
  request_id
  status            0-未读 1-已读（推送场景）
  created_at
```

约束：

- `request_id` 在主动推送场景需唯一（用于幂等）。
- 不保存 DeepSeek 的 `reasoning_content`。

### 2.2 user_ai_stamina

```text
user_ai_stamina
  user_id
  stamina
  max_stamina
  last_recover_at
  daily_used_date
  daily_used_count
  create_time
  update_time
```

约束：

- `stamina` 范围：`0 <= stamina <= max_stamina`。
- 扣减与恢复必须写体力流水。

### 2.3 user_ai_stamina_log

```text
user_ai_stamina_log
  id
  user_id
  biz_type
  biz_id
  amount
  stamina_after
  remark
  create_time
```

biz_type 建议值：

- `CHAT_COST`
- `NATURAL_RECOVER`
- `APPLE_RECOVER`
- `ADMIN_GRANT`

### 2.4 user_ai_memory

```text
user_ai_memory
  id
  user_id
  flag_key
  flag_value
  flag_meta
  updated_at
  created_at
```

常用 Flag：

- `biggest_win_amount`
- `biggest_win_event`
- `first_egg_turtle`
- `longest_win_streak`
- `longest_lose_streak`
- `total_dialogue_count`

### 2.5 template_user_view

```text
template_user_view
  id
  user_id
  template_id
  view_count
  last_viewed_at
```

约束：

- `(user_id, template_id)` 唯一。
- 用于模板去重与曝光控制。

### 2.6 user_ai_presence

```text
user_ai_presence
  user_id
  page
  active
  first_seen_at
  last_seen_at
  last_ai_interact_at
  last_idle_push_at
  idle_push_count_date
  idle_push_count
```

用途：

- 闲置用户识别。
- 冷却窗口和每日上限控制。

## 3. 关系与一致性

### 3.1 关键关系

- `ai_message.user_id -> user.id`
- `user_ai_stamina.user_id -> user.id`
- `user_ai_memory.user_id -> user.id`
- `template_user_view.user_id -> user.id`

### 3.2 一致性规则

1. DeepSeek 调用失败不扣体力。
2. 主动推送不消耗体力。
3. 推送先落库再投递，保证离线可补拉。
4. 结算推送用 `request_id` 保证幂等。

## 4. 索引建议

- `ai_message(user_id, created_at)`
- `ai_message(request_id)` 唯一索引
- `user_ai_memory(user_id, flag_key)`
- `user_ai_presence(last_ai_interact_at)`
- `template_user_view(user_id, template_id)` 唯一索引
