## EXT-STAMINA-01 宠物体力减免能力

### 接口定义

- 接口名：`PetAbilityService.GetAIStaminaReduction`
- 调用方向：AI 系统 -> 宠物系统
- 调用方式：同步 RPC/HTTP

### 输入参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| userId | int64 | 是 | 用户 ID |
| abilityKey | string | 是 | 固定值 `stamina_reduction` |

### 输出参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| enabled | bool | 是否生效 |
| reductionRatio | float | 减免比例，范围 `[0, 1]` |

### 错误码

| 错误码 | 触发条件 |
| --- | --- |
| PET_ABILITY_NOT_FOUND | 用户未装备可用能力 |
| PET_SERVICE_UNAVAILABLE | 宠物服务超时/不可用 |

### 固定策略

- 超时：300ms
- 重试：1 次，间隔 100ms
- 熔断：30s 窗口内失败率 > 50% 则熔断 60s
- 并发：按 userId 局部串行
- 限速：200 QPS

### 验收标准

- 体力减免在聊天扣减前生效。
- 宠物服务不可用时降级为不减免，不阻断聊天主流程。

## EXT-PREDICT-01 预测市场上下文查询

### 接口定义

- 接口名：`PredictContextService.GetContextForAI`
- 调用方向：AI 系统 -> 预测市场系统
- 调用方式：同步 HTTP

### 输入参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| contextType | string | 是 | 固定值 `predict_market` |
| contextId | int64 | 是 | 预测市场上下文 ID |

### 输出参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| title | string | 市场标题 |
| options | array | 选项与赔率快照 |
| deadline | int64 | 截止时间 |

### 错误码

| 错误码 | 触发条件 |
| --- | --- |
| PREDICT_CONTEXT_NOT_FOUND | 上下文不存在 |
| PREDICT_SERVICE_UNAVAILABLE | 服务不可用 |

### 固定策略

- 超时：500ms
- 重试：2 次，指数退避 100ms/300ms
- 熔断：1 分钟窗口失败 10 次触发熔断 2 分钟
- 并发：500 并发
- 限速：300 QPS

### 验收标准

- 提供给 LLM 的市场信息完整且不含敏感字段。

## EXT-COIN-01 苹果购买与龟币扣减

### 接口定义

- 接口名：`UserCoinService.Deduct`
- 调用方向：AI 系统 -> 金币系统
- 调用方式：同步本地服务

### 输入参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| userId | int64 | 是 | 用户 ID |
| amount | int64 | 是 | 扣减金额 |
| bizType | string | 是 | 固定值 `AI_APPLE_BUY` |
| bizId | string | 是 | 幂等流水号 |

### 输出参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| balanceAfter | int64 | 扣减后余额 |

### 错误码

| 错误码 | 触发条件 |
| --- | --- |
| COIN_NOT_ENOUGH | 余额不足 |
| COIN_BIZ_DUPLICATE | bizId 重复 |

### 固定策略

- 超时：300ms
- 重试：0 次
- 熔断：失败率 > 40% 持续 30s 熔断 60s
- 并发：按 userId 串行扣减
- 限速：1000 QPS

### 验收标准

- 扣币与体力恢复在同一事务中成功或失败。

## EXT-PREDICT-02 结算完成事件发布

### 接口定义

- 接口名：`PredictSettleEvent`
- 调用方向：预测市场系统 -> AI 系统
- 调用方式：异步事件总线

### 输入参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| userId | int64 | 是 | 用户 ID |
| bizType | string | 是 | 业务类型 |
| bizId | string | 是 | 业务 ID |
| settleResult | string | 是 | win/lose/void |
| profitAmount | int64 | 是 | 盈亏金额 |

### 输出参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| accepted | bool | 是否接收成功 |

### 错误码

| 错误码 | 触发条件 |
| --- | --- |
| EVENT_DUPLICATE | 事件重复 |
| EVENT_PARSE_FAILED | 事件格式错误 |

### 固定策略

- 超时：异步消费单条 1s
- 重试：3 次，间隔 1s/3s/5s
- 熔断：消费失败率 > 30% 持续 1 分钟熔断 2 分钟
- 并发：消费者并发 20
- 限速：500 events/s

### 验收标准

- 事件重复投递不生成重复推送消息。
