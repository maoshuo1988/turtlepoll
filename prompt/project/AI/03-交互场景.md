# AI 聊天交互场景

> 本文按用户和系统触发场景整理交互口径。

## 1. 用户主动聊天

### 1.1 比赛或预测分析

用户示例：

```text
帮我看看这场曼城对阿森纳应该买哪边
```

处理规则：

1. 校验登录和 AI 功能开关。
2. 校验体力，体力不足不调用 LLM。
3. 若带 `contextType=predict_market`，读取站内预测市场上下文。
4. 调用 DeepSeek 生成辅助分析。
5. 回复中不能承诺稳赢，不能鼓励重仓。

### 1.2 普通闲聊

处理规则：

- 使用小龟人格。
- 回复短一些。
- 不主动提起历史记忆。
- 不暴露模型身份。

### 1.3 AI 身份问答

用户示例：

```text
你是不是 ChatGPT?
```

推荐直接规则兜底：

```text
我是你的小龟啦!你养的那个,陪你聊天看比赛的那个。怎么突然问这个,是觉得我哪里不对劲吗?
```

## 2. 投票结算推送

触发点：用户投票结算后，由后端立即触发。

规则：

- 不消耗体力。
- 不调用 LLM。
- 从模板池选择文案。
- 支持 `{amount}` 和 `{n}` 占位符。

### 2.1 赢

场景：`win`

占位符：

- `{amount}`：盈利龟币数。

候选文案见 [06-Prompt与模板.md#5-种子模板](./06-Prompt与模板.md#5-种子模板)。

### 2.2 输

场景：`lose`

占位符：

- `{amount}`：损失龟币数。

### 2.3 连胜

场景：`win_streak`

触发条件：

- 当前连胜 `>= 3`。

占位符：

- `{n}`：当前连胜场数。

### 2.4 连败

场景：`lose_streak`

触发条件：

- 当前连败 `>= 5`。

占位符：

- `{n}`：当前连败场数。

### 2.5 多场景命中

如果一次结算同时命中普通输赢和 streak：

- MVP 建议最多推一条。
- 优先级：`lose_streak / win_streak` 高于 `lose / win`。

## 3. 闲置记忆推送

触发条件：

- 用户在 App 内停留 `>= 10 分钟`。
- 最近 `10 分钟` 没有和小龟互动。
- 冷却期 `60 分钟`。
- 每日最多 `2 条` 记忆类消息。

规则：

- 不消耗体力。
- 不调用 LLM。
- 用户回复后才进入正式对话，从回复那条开始消耗体力。
- 没有对应记忆数据时跳过。

### 3.1 最大盈利回调

场景：`idle_biggest_win`

建议页面：

- 投票页。

所需数据：

- `match_date`
- `league`
- `amount`

### 3.2 首次开蛋回调

场景：`idle_first_egg`

建议页面：

- 装扮页。

所需数据：

- `turtle_name`

### 3.3 最长连胜回调

场景：`idle_longest_streak`

建议页面：

- 主页。

所需数据：

- `n`
- `time_ago`

## 4. 用户主动问记忆

用户问“你还记得……”“我之前最多……”“我第一只龟……”等句式时，后端读取记忆 Flag，并把事实拼入 Prompt。

规则：

- 消耗体力。
- 调用 DeepSeek。
- 只能依据后端提供的事实回答。
- 没有记录时不编造。

### 4.1 支持问题

| 问题类型 | 所需 Flag |
| --- | --- |
| 最大盈利 | `biggest_win_amount`、`biggest_win_event` |
| 首次开蛋 | `first_egg_turtle` |
| 连续登录 | `current_login_streak` |
| 历史最长连胜 | `longest_win_streak` |
| 历史最长连败 | `longest_lose_streak` |
| 累计对话次数 | `total_dialogue_count` |
| 已收集龟种数 | `total_turtles_owned` |

### 4.2 没有记录

兜底口径：

```text
……抱歉哎,具体某天的事我记不清,我只能记得一些比较关键的时刻——你最赚的一次、最长连胜、第一次抽到的龟之类。要看具体战绩你可以去状态页查。
```

## 5. 边界场景

| 场景 | 处理 |
| --- | --- |
| 体力为 0 | 系统兜底，不调用 LLM。 |
| 用户辱骂 | 可直接返回 `……`。 |
| 敏感话题 | 不直接判断，引导查看 App 内预测市场热度。 |
| 长时间未互动后回归 | 可用模板或 LLM 返回“好久不见”类文案。 |
| 新用户首次对话 | 介绍小龟身份，可询问是否起名。 |
| DeepSeek 超时 | 返回降级文案，不扣体力。 |
| 模板池为空 | 不发送主动推送。 |

## 6. 连胜/连败计算

建议口径：

- 用户赢一场：`vote_win_streak + 1`，`vote_lose_streak = 0`。
- 用户输一场：`vote_lose_streak + 1`，`vote_win_streak = 0`。
- 平局、退款、作废：不改变 streak。

最终以结算服务的实际状态定义为准。
