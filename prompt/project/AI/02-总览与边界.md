# AI 聊天系统总览与边界

> 本文整理 AI 聊天系统的目标、范围、核心规则、模块边界和优先级。

## 1. 系统目标

1. 提供用户主动发起的"小龟 AI 对话"能力，支持闲聊、比赛分析、身份问答。
2. 用户询问历史记忆时，小龟可基于事实回答。
3. 投票结算后系统主动推送小龟鼓励或提醒文案。
4. 用户长时间停留但未互动时，触发记忆类闲置推送。
5. 接入体力消耗规则：主动对话消耗体力，主动消息不消耗。
6. 小龟语气保持温和、靠谱、有点小可爱。

## 2. 本期范围

| 模块 | 本期 | 说明 |
| --- | --- | --- |
| 用户主动聊天 | ✓ | 调用 DeepSeek，支持普通聊天和预测分析 |
| AI 身份问答 | ✓ | 不暴露底层模型，统一回答为"小龟" |
| 体力校验 | ✓ | 体力不足不调用 LLM，返回兜底文案 |
| 投票结算推送 | ✓ | 模板池随机，不调用 LLM |
| 连胜/连败推送 | ✓ | 结算后根据 streak 触发 |
| 用户主动问记忆 | ✓ | 读取业务 Flag 后调用 LLM 表达 |
| 闲置记忆推送 | ✓ | 模板池随机，不调用 LLM |
| 模板去重 | ✓ | 优先选用户未见过或见过最少的模板 |
| SSE 在线推送 | ✓ | 支持心跳和 Last-Event-ID 补发 |
| 未读推送拉取 | ✓ | 断线或离线用户补拉 |

## 3. 核心规则

### 3.1 体力与 LLM 调用矩阵

| 场景 | 消耗体力 | 调用 LLM | 说明 |
| --- | --- | --- | --- |
| 用户主动聊天 | 是 | 是 | 实时回复 |
| 用户主动问记忆 | 是 | 是 | 基于内存 Flag 的 LLM 表达 |
| 用户回复闲置推送 | 是 | 是 | 继续对话 |
| 投票结算主动推送 | 否 | 否 | 模板文案 |
| 闲置记忆主动推送 | 否 | 否 | 模板文案 |
| 体力为 0 时主动聊天 | 否 | 否 | 返回兜底，不调用 |

### 3.2 记忆触发范围

记忆系统只在两种情况触发：

1. **用户主动问**：例如"我之前最多赢过多少？"
2. **闲置推送**：例如用户停留很久但未互动

普通比赛分析、闲聊、身份问答中，AI 不应主动提起用户过去的事。

### 3.3 主动消息规则

所有 AI 主动发起的消息均不消耗体力：

- 投票结算推送
- 连胜/连败推送
- 闲置记忆推送
- 断线重连消息

本期主动消息使用模板池，不实时调用 DeepSeek。

### 3.4 小龟语气

- **温和**：不生硬
- **靠谱**：给出实际帮助
- **有点小可爱**：偶有俏皮语气
- **禁止**：不煽情、不说教、不强行安慰、不鼓励重仓

## 4. 模块边界

### 4.1 用户侧功能

- 聊天界面展示历史消息
- 发送消息前检查体力
- 接收在线 SSE 推送
- 轮询未读消息
- 标记推送已读

### 4.2 后端核心服务

- `AIService`：主动聊天、记忆问答、LLM 调用
- `AIPushService`：结算推送、闲置推送、模板选择
- `AIStaminaService`：体力查询、恢复、消耗
- `AIPresenceService`：用户在线状态、活跃时间

### 4.3 不在本期范围内

| 项目 | 原因 |
| --- | --- |
| 心情系统 | 需求明确本期不做 |
| 装备龟影响语气 | 需为不同龟种设计 Prompt，后置 |
| AI 自然提起历史记忆 | 容易造成越界和编造 |
| 生日/节日/里程碑祝贺 | 需要更多成就口径，后续再加 |
| AI 主动日常闲聊 | 本期主动消息仅做结算和记忆回调 |
| 自动补充实时模板池 | 可作为异步后台能力后续补 |

## 5. 技术约束

| 约束 | 说明 |
| --- | --- |
| LLM 非决策依据 | LLM 输出不能作为下注、结算、派奖依据 |
| API Key 隔离 | DeepSeek Key 只能放服务端 |
| 输入长度限制 | 用户输入进入 LLM 前做长度限制 |
| 失败不扣体力 | DeepSeek 失败时不应扣体力 |
| 模型隐藏 | 不能向用户暴露 DeepSeek、ChatGPT 等模型身份 |
| 敏感数据不记录 | 对话历史不保存 DeepSeek 的 reasoning_content |
| 身份兜底 | 对身份相关问题回答一致 |

## 6. 优先级

- **P0**：主动聊天、体力系统、结算推送、基础记忆
- **P1**：闲置推送、记忆问答、模板去重、SSE 推送
- **P2**：多语言、钉钉通知集成、敏感话题识别
