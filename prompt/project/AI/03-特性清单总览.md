## 4. DeepSeek 调用策略

| 场景 | 是否调用 DeepSeek | 模型 | thinking | 说明 |
| --- | --- | --- | --- | --- |
| 普通闲聊 | 是 | `deepseek-v4-flash` | disabled | 默认低成本模型。 |
| AI 身份问答 | 可不调用 | 无 | 无 | 推荐规则兜底。 |
| 比赛/预测简单分析 | 是 | `deepseek-v4-flash` | disabled | 基于站内上下文生成简短分析。 |
| 复杂预测分析 | 是 | `deepseek-v4-pro` | enabled | 可使用 `reasoning_effort=high`。 |
| 用户主动问记忆 | 是 | `deepseek-v4-flash` | disabled | 事实由后端提供。 |
| 投票结算推送 | 否 | 无 | 无 | 只走模板。 |
| 闲置推送 | 否 | 无 | 无 | 只走模板。 |
| 体力不足 | 否 | 无 | 无 | 系统兜底。 |
| DeepSeek 不可用 | 否 | 无 | 无 | 系统降级文案。 |

## 7. 验收重点

1. 体力不足时不调用 DeepSeek。
2. 主动推送不消耗体力。
3. 主动推送不实时调用 DeepSeek。
4. 普通分析不会主动提起历史记忆。
5. 问模型身份不会暴露底层模型。
6. DeepSeek 调用失败不扣体力。
7. 模板去重能避免同一用户短期反复看到同一句。
