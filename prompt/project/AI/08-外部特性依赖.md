## 依赖优先级

- **P0（必须）**：预测市场上下文、结算事件、苹果购买、金币流水
- **P1（计划中）**：宠物体力减免、敏感话题分类、多模型

## 调用关系拓扑

```
AI 系统
  ├─ 查询 → 预测市场系统（上下文）
  ├─ 监听 ← 预测市场系统（结算事件）
  ├─ 调用 → 金币系统（购买苹果、扣体力费、发放福利）
  ├─ 查询 → 宠物系统（装备龟种、体力减免能力）
  └─ 查询 → 自身存储（用户记忆 Flag）
```
