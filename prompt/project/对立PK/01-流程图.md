# 对立PK：流程图

## 赛季推进流程

```mermaid
flowchart TD
  A[启用PK话题] --> B{是否存在活动赛季}
  B -->|否| C[创建赛季 seasonNo+1]
  B -->|是| D[读取活动赛季]
  C --> E{是否存在当前回合}
  D --> E
  E -->|否| F[创建第1局 roundNo=1]
  E -->|是| G[进入回合推进]
  F --> G
  G --> H[每局结算更新 winsA/winsB/totalRounds]
  H --> I{now>=seasonEndTime}
  I -->|否| J[创建下一局]
  J --> G
  I -->|是| K[计算冠军 A/B/draw]
  K --> L[归档旧赛季]
  L --> M[创建新赛季并开第1局]
  M --> G
```

## 单局回合流程

```mermaid
flowchart TD
  A[创建PKRound] --> B[phase=betting 0-48h]
  B --> C[下注: 每用户每局一次]
  B --> D[评论/点赞/回复/拉踩]
  C --> E[更新 poolA/poolB betCountA/betCountB]
  D --> F[更新互动热度]
  E --> G[刷新 heatA/heatB]
  F --> G
  G --> H{now>=lockTime}
  H -->|否| B
  H -->|是| I[phase=locked 48-72h]
  I --> J[禁止下注 仅允许互动]
  J --> K{now>=endTime}
  K -->|否| I
  K -->|是| L[冻结数据并计算最终热度]
  L --> M{heatA vs heatB}
  M -->|A高| N[winner=A]
  M -->|B高| O[winner=B]
  M -->|相等| P[winner=draw]
  N --> Q[生成结算明细]
  O --> Q
  P --> Q
  Q --> R[phase=cooldown 10m]
  R --> S{now>=nextRoundTime}
  S -->|否| R
  S -->|是| T[创建下一局]
```

## 用户收益流程

```mermaid
flowchart TD
  A[用户进入PK详情] --> B{phase=betting}
  B -->|否| C[不可下注 可互动]
  B -->|是| D[选择A/B并提交 requestId]
  D --> E{同回合是否已下注}
  E -->|是| F[幂等返回已下注结果]
  E -->|否| G[扣减100龟币入池]
  G --> H[创建PKBet]
  H --> I[等待结算]
  I --> J{回合结果}
  J -->|win| K[返还本金+按占比分配败方池]
  J -->|lose| L[payout=0]
  J -->|draw| M[退还本金]
  K --> N[写入金币流水]
  L --> N
  M --> N
```

## 幂等与事务约束

- 下注幂等键：topicId + roundId + userId + requestId。
- 下注唯一键：roundId + userId。
- 回合结算唯一键：roundId。
- 派奖唯一键：roundId + userId。
- 下一局唯一键：topicId + roundNo。
- 下一赛季唯一键：topicId + seasonNo。
