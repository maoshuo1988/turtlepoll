# 对立PK：流程图

## 赛季推进流程

```mermaid
flowchart TD
  A[启用PK话题] --> B{是否存在活动赛季}
  B -->|否| C[创建赛季 seasonNo+1]
  B -->|是| D[读取活动赛季]
  C --> E{是否存在当前回合}
  D --> E
  E -->|否| F[创建第1局 roundNo=1]
  E -->|是| G[进入回合推进]
  F --> G
  G --> H[每局结算更新 winsA/winsB/totalRounds]
  H --> I{now>=seasonEndTime}
  I -->|否| J[创建下一局]
  J --> G
  I -->|是| K[计算冠军 A/B/draw]
  K --> L[归档旧赛季]
  L --> M[创建新赛季并开第1局]
  M --> G
```

## 单局回合流程

```mermaid
flowchart TD
  A[创建PKRound] --> B[phase=betting 0-48h]
  B --> C[下注: 每用户每局一次]
  B --> D[评论/点赞/回复]
  C --> E[更新 poolA/poolB betCountA/betCountB]
  D --> F[调用热度计算服务]
  E --> G[提交互动输入]
  F --> H[刷新 options[] 热度快照]
  G --> H
  H --> I{now>=lockTime}
  I -->|否| B
  I -->|是| J[phase=locked 48-72h]
  J --> K[禁止下注 仅允许互动]
  K --> L{now>=endTime}
  L -->|否| J
  L -->|是| M[进入可结算状态 等待用户触发]
  M --> N[用户调用 /api/pk/settle]
  N --> O[读取撕裂带热度快照]
  O --> P{A.hTotal vs B.hTotal}
  P -->|A高| Q[winner=A]
  P -->|B高| R[winner=B]
  P -->|相等| S[winner=draw]
  Q --> T[生成结算明细并派奖]
  R --> T
  S --> T
  T --> U[phase=cooldown 10m]
  U --> V{now>=nextRoundTime}
  V -->|否| U
  V -->|是| W[创建下一局]
```

## 用户收益流程

```mermaid
flowchart TD
  A[用户进入PK详情] --> B{phase=betting}
  B -->|否| C[不可下注 可互动]
  B -->|是| D[选择A/B并提交 requestId]
  D --> E{同回合是否已下注}
  E -->|是| F[幂等返回已下注结果]
  E -->|否| G[按请求金额扣减龟币入池]
  G --> H[创建PKBet]
  H --> I[等待结算]
  I --> J[任意用户触发 /api/pk/settle]
  J --> K{回合结果}
  K -->|win| L[本金 + 败方奖池×本人下注占比]
  K -->|lose| M[payout=0]
  K -->|draw| N[退还本金]
  L --> O[写入金币流水]
  M --> O
  N --> O
```

## 幂等与事务约束

- 下注幂等键：topicId + roundId + userId + requestId。
- 下注唯一键：roundId + userId。
- 回合结算唯一键：roundId。
- 派奖唯一键：roundId + userId。
- 下一局唯一键：topicId + roundNo。
- 下一赛季唯一键：topicId + seasonNo。

## 后端定时轮询时序

```mermaid
sequenceDiagram
  participant Scheduler as 定时调度器<br/>（每分钟）
  participant PKService as 对立PK服务
  participant DB as 数据库
  
  loop 每分钟执行一次
    Scheduler ->> PKService: pk_round_tick()
    
    PKService ->> DB: 扫描 phase=betting且now>=lockTime 的回合
    DB -->> PKService: 返回结果集
    
    alt 存在符合条件的回合
      PKService ->> DB: UPDATE phase=locked
    end
    
    PKService ->> DB: 扫描 phase=locked且now>=endTime 的回合
    DB -->> PKService: 返回结果集
    
    alt 存在符合条件的回合
      PKService ->> DB: UPDATE phase=cooldown（进入可结算窗口）
    end
    
    PKService ->> DB: 扫描 phase=cooldown且now>=nextRoundTime 的回合
    DB -->> PKService: 返回结果集
    
    alt 存在符合条件的回合
      PKService ->> DB: INSERT 新回合<br/>UPDATE 话题current_round_id
    end
    
    PKService ->> DB: 检查活动赛季到期
    
    alt 赛季到期
      PKService ->> DB: 计算冠军<br/>UPDATE 赛季状态=finished<br/>INSERT 新赛季
    end
  end
```

## 对立PK与撕裂带热度计算交互时序

```mermaid
sequenceDiagram
  participant User as 用户
  participant PKSvc as 对立PK服务
  participant HeatSvc as 撕裂带热度服务
  participant Cache as 热度缓存
  
  par 下注流程
    User ->> PKSvc: POST /api/pk/bet<br/>(topicId, roundId, side, amount)
    PKSvc ->> HeatSvc: 写入互动日志与用户事件统计<br/>(t_tear_interact_log / t_tear_user_event_stat)
    HeatSvc ->> HeatSvc: 累计BetAmount<br/>计算H_coin=amount×0.02
    HeatSvc -->> PKSvc: OK
    PKSvc ->> PKSvc: 扣减龟币<br/>更新poolA/poolB
    PKSvc ->> Cache: 触发ComputeHeatSnapshot()
    Cache ->> HeatSvc: 读取最新热度汇总
    HeatSvc -->> Cache: 返回(options[])
    Cache -->> PKSvc: 缓存热度
    PKSvc -->> User: 返回(betId, options[], oddsA, oddsB)
  and 评论与互动流程
    User ->> PKSvc: POST /api/pk/comment/create<br/>(roundId, side, content)
    PKSvc ->> HeatSvc: 写入互动日志与用户事件统计<br/>(actionType=comment)
    HeatSvc ->> HeatSvc: 计算评论热度<br/>H_comment=min(3×(1+log(1+L)), 20)
    HeatSvc -->> PKSvc: OK
    PKSvc ->> Cache: 触发ComputeHeatSnapshot()
    Cache ->> HeatSvc: 读取最新热度汇总
    HeatSvc -->> Cache: 返回(options[])
    Cache -->> PKSvc: 缓存热度
    PKSvc -->> User: 返回(commentId)
  and 点赞流程
    User ->> PKSvc: POST /api/pk/like<br/>(commentId)
    PKSvc ->> HeatSvc: 写入互动日志与用户事件统计<br/>(actionType=like)
    HeatSvc ->> HeatSvc: 累计H_like += 1
    HeatSvc -->> PKSvc: OK
    PKSvc ->> Cache: 触发ComputeHeatSnapshot()
    Cache ->> HeatSvc: 读取最新热度汇总
    HeatSvc -->> Cache: 返回(options[])
    Cache -->> PKSvc: 缓存热度
    PKSvc -->> User: 返回(likeCount)
  end
  
  User ->> PKSvc: GET /api/pk/heat<br/>(topicId, roundId)
  PKSvc ->> Cache: 读取缓存热度
  Cache -->> PKSvc: 返回(options[])
  PKSvc -->> User: 返回(options[])
```

## 用户触发结算时序

```mermaid
sequenceDiagram
  participant User as 用户
  participant PKSvc as 对立PK服务
  participant HeatSvc as 撕裂带热度服务
  participant CoinSvc as 金币服务
  participant DB as 数据库
  
  User ->> PKSvc: POST /api/pk/settle<br/>(topicId, roundId, requestId)
  
  PKSvc ->> DB: 校验回合<br/>1. 回合存在<br/>2. now >= endTime<br/>3. settledAt=0
  DB -->> PKSvc: 返回回合信息
  
  PKSvc ->> DB: SELECT * FROM PKBet<br/>WHERE roundId<br/>GROUP BY side
  DB -->> PKSvc: 返回(poolA, poolB, betCountA, betCountB)
  
  alt 尚无 FROZEN 快照
    PKSvc ->> HeatSvc: ComputeHeatSnapshot<br/>(bizType=PK, bizId, roundId,<br/>snapshotType=SETTLE, freezeSource=ON_DEMAND)
    HeatSvc -->> PKSvc: 返回(options[], snapshotTime)
  end

  PKSvc ->> HeatSvc: GetHeatSnapshot<br/>(bizType=PK, bizId, roundId,<br/>snapshotType=SETTLE)
  HeatSvc ->> DB: 读取t_tear_heat_snapshot<br/>最新FROZEN态快照
  DB -->> HeatSvc: 返回(options[])
  HeatSvc -->> PKSvc: 返回快照
  
  PKSvc ->> PKSvc: 判定胜负<br/>if A.hTotal > B.hTotal: winner=A<br/>else if B.hTotal > A.hTotal: winner=B<br/>else: winner=draw
  
  PKSvc ->> DB: BEGIN TRANSACTION
  
  PKSvc ->> DB: UPDATE PKRound<br/>winner, heatA, heatB
  
  alt winner != draw
    PKSvc ->> PKSvc: 计算派奖<br/>for each user in winnerSide:<br/>  payout = principal<br/>          + loserPool × userBet / winnerTotalBet
    
    PKSvc ->> DB: INSERT PKSettle<br/>WITH payout信息
    
    loop for each winner user
      PKSvc ->> CoinSvc: Credit<br/>(userId, payout,<br/>bizType=PK_SETTLE, bizId=roundId,<br/>subBizId=userId)
      CoinSvc ->> CoinSvc: 检查幂等<br/>同bizType+bizId+subBizId不重复入账
      CoinSvc ->> DB: INSERT UserCoinLog
      DB -->> CoinSvc: OK
      CoinSvc -->> PKSvc: OK
    end
  else winner = draw
    PKSvc ->> PKSvc: 平局派奖<br/>for each user in all sides:<br/>  payout = principal（原路退回）
    
    PKSvc ->> DB: INSERT PKSettle<br/>WITH payout信息
    
    loop for each user
      PKSvc ->> CoinSvc: Credit<br/>(userId, principal,<br/>bizType=PK_DRAW_REFUND, bizId=roundId,<br/>subBizId=userId)
      CoinSvc -->> PKSvc: OK
    end
  end
  
  PKSvc ->> DB: UPDATE PKRound<br/>phase=cooldown
  
  PKSvc ->> DB: COMMIT TRANSACTION
  
  PKSvc -->> User: 返回(roundId, winner,<br/>options[],<br/>settledUserCount,<br/>totalPayoutAmount)
  
  Note over PKSvc,User: 结算完成，等待10分钟后<br/>定时任务创建下一局
```
