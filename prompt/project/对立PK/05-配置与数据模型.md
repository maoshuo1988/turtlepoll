# 对立PK：配置与数据模型

## 1. 配置项

| 配置键 | 默认值 | 说明 |
|--------|--------|------|
| pk.bet.amount | 100 | 单次下注金额（龟币） |
| pk.round.betting_hours | 48 | 下注期时长（小时） |
| pk.round.locked_hours | 24 | 锁局期时长（小时） |
| pk.round.cooldown_minutes | 10 | 冷却期时长（分钟） |
| pk.season.days | 30 | 赛季时长（天） |
| pk.heat.comment_cap | 20 | 单评论热度上限 |
| pk.heat.bet_factor | 0.5 | 下注热度系数 |

## 2. 核心数据模型

### PKTopic

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int64 | 主键 |
| slug | string | 业务唯一标识 |
| title | string | 话题标题 |
| side_a_name | string | A 阵营名称 |
| side_b_name | string | B 阵营名称 |
| status | string | enabled/disabled |
| current_round_id | int64 | 当前回合ID |
| current_season_id | int64 | 当前赛季ID |

### PKRound

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int64 | 主键 |
| topic_id | int64 | 话题ID |
| season_id | int64 | 赛季ID |
| round_no | int | 回合序号 |
| phase | string | betting/locked/cooldown/settled |
| start_time | int64 | 开始时间戳 |
| lock_time | int64 | 锁局时间戳 |
| end_time | int64 | 结束时间戳 |
| next_round_time | int64 | 下一局创建时间戳 |
| pool_a | int64 | A 奖池 |
| pool_b | int64 | B 奖池 |
| bet_count_a | int64 | A 下注人数 |
| bet_count_b | int64 | B 下注人数 |
| heat_a | float64 | A 热度 |
| heat_b | float64 | B 热度 |
| winner | string | A/B/draw；draw 表示热度相同的完全中立平局 |

### PKBet

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int64 | 主键 |
| topic_id | int64 | 话题ID |
| round_id | int64 | 回合ID |
| user_id | int64 | 用户ID |
| side | string | A/B |
| amount | int64 | 下注金额 |
| request_id | string | 幂等键 |
| settle_result | string | win/lose/draw；draw 表示本金原路退回且不影响连胜、排名、推送 |
| payout | int64 | 派彩金额 |

唯一索引：

- uk_round_user(round_id, user_id)
- uk_round_user_req(round_id, user_id, request_id)

### PKSeason

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int64 | 主键 |
| topic_id | int64 | 话题ID |
| season_no | int | 赛季编号 |
| start_time | int64 | 开始时间戳 |
| end_time | int64 | 结束时间戳 |
| wins_a | int | A 胜场 |
| wins_b | int | B 胜场 |
| total_rounds | int | 总回合 |
| champion | string | A/B/draw |
| status | string | active/finished |

### PKCommentMeta

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int64 | 主键 |
| comment_id | int64 | 评论ID |
| topic_id | int64 | 话题ID |
| round_id | int64 | 回合ID |
| side | string | A/B |
| quality_score | float64 | 质量分 |
| downvote_count | int64 | 拉踩数 |
| heat_score | float64 | 评论热度 |

### PKAction

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int64 | 主键 |
| topic_id | int64 | 话题ID |
| round_id | int64 | 回合ID |
| user_id | int64 | 用户ID |
| side | string | 热度归属阵营 |
| action_type | string | like/comment/reply/downvote/bet |
| entity_type | string | 关联实体类型 |
| entity_id | int64 | 关联实体ID |
| amount | int64 | 数值量 |
| heat | float64 | 贡献热度 |

## 3. 复用模型映射

| 复用模型 | 用途 | 约束 |
|----------|------|------|
| UserCoin/UserCoinLog | 下注扣款与派奖 | 不新建第二套余额系统 |
| Comment | 评论与回复正文 | 阵营信息不落 Comment |
| UserLike | 点赞行为 | 通过 PKAction 聚合到热度 |
