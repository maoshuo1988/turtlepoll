# 对立PK：接口

## 1. 用户侧接口（/api/pk）

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/pk/topics | GET | PK话题列表 |
| /api/pk/topic | GET | PK话题详情 |
| /api/pk/bet | POST | 当前回合下注 |
| /api/pk/heat | GET | 当前回合热度 |
| /api/pk/comments | GET | 阵营评论列表 |
| /api/pk/comment/create | POST | 发布PK评论 |
| /api/pk/comment/reply | POST | 回复PK评论 |
| /api/pk/downvote | POST | 拉踩评论 |
| /api/pk/history | GET | 历史回合 |
| /api/pk/seasons | GET | 赛季历史 |
| /api/pk/my/bets | GET | 我的下注记录 |

### 1.1 下注意向接口定义

- 接口名：PlacePKBet
- URL：POST /api/pk/bet
- 输入参数：topicId(int64,必填), side(string,必填,A/B), requestId(string,必填)
- 输出参数：betId, roundId, side, amount, oddsA, oddsB, heatA, heatB, balanceAfter
- 错误码：
  - PK_401_UNAUTHORIZED：未登录
  - PK_404_TOPIC_NOT_FOUND：话题不存在
  - PK_409_ROUND_NOT_BETTING：非下注期
  - PK_409_ALREADY_BET：本局已下注
  - PK_422_INVALID_SIDE：side 非法
  - PK_507_INSUFFICIENT_COIN：余额不足

## 3. 路由绑定规范（Iris MVC）

当 URL 含短横线或多级路径时，必须在 BeforeActivation 显式绑定。

示例：

```go
import "github.com/kataras/iris/v12/mvc"

func (c *PkController) BeforeActivation(b mvc.BeforeActivation) {
    b.Handle("POST", "/bet", "PostBet")
    b.Handle("GET", "/my/bets", "GetMyBets")
}
```

## 4. 验证要求

1. 新增接口必须按文档 URL 使用 curl 实测。
2. 对 /api/admin/** 同时验证 cookie 与 bearer token 两种认证方式。
3. 返回 HTML 首页视为路由未命中，不算通过。
