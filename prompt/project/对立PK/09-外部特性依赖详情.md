# 对立PK：外部特性依赖详情

## F01 用户金币账户与流水

### 接口定义

- 接口名：SpendToPool / PayFromPoolToUser / BurnFromPool
- 调用方向：PKService -> UserCoinService
- 调用方式：进程内服务调用

### 输入参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | int64 | 是 | 用户ID |
| amount | int64 | 是 | 金额，单位龟币 |
| bizType | string | 是 | 业务类型（PK_BET_STAKE_IN/PK_PAYOUT/PK_DRAW_REFUND） |
| bizId | int64 | 是 | 业务主键（betId或roundId） |

### 输出参数

| 字段 | 类型 | 说明 |
|------|------|------|
| ok | bool | 是否成功 |
| balanceAfter | int64 | 账户变更后余额 |
| coinLogId | int64 | 流水ID |

### 错误码

| 错误码 | 触发条件 |
|--------|----------|
| COIN_507_INSUFFICIENT | 余额不足 |
| COIN_409_DUP_BIZ | 相同bizType+bizId重复入账 |
| COIN_500_INTERNAL | 账户写入异常 |

### 固定策略

- 超时：300ms。
- 重试：最多 2 次，间隔 50ms，仅对网络抖动或连接中断重试。
- 熔断：30 秒窗口内错误率 >= 40% 且请求数 >= 50 时打开，打开后 60 秒半开探测。
- 并发：单实例最大 200 并发调用。
- 限速：每实例每秒 500 次。

### 验收标准

- 下注幂等重试不出现重复扣款。
- 结算重试不出现重复派奖。

## F02 通用评论发布与回复

### 接口定义

- 接口名：PublishComment / PublishReply
- 调用方向：PKCommentService -> CommentService
- 调用方式：进程内服务调用

### 输入参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | int64 | 是 | 用户ID |
| entityType | string | 是 | pk_topic 或 comment |
| entityId | int64 | 是 | 话题ID或父评论ID |
| content | string | 是 | 评论内容 |
| imageList | []string | 否 | 图片URL列表 |
| quoteId | int64 | 否 | 引用评论ID |

### 输出参数

| 字段 | 类型 | 说明 |
|------|------|------|
| commentId | int64 | 评论ID |
| createTime | int64 | 创建时间戳 |

### 错误码

| 错误码 | 触发条件 |
|--------|----------|
| COMMENT_422_INVALID_CONTENT | 内容为空或超长 |
| COMMENT_403_FORBIDDEN | 用户无评论权限 |
| COMMENT_500_INTERNAL | 评论写入失败 |

### 固定策略

- 超时：400ms。
- 重试：0 次，评论发布不自动重试，防止重复内容。
- 熔断：60 秒窗口内错误率 >= 30% 且请求数 >= 30 时打开，保持 30 秒。
- 并发：单实例最大 150 并发调用。
- 限速：用户维度 30 次/分钟，IP 维度 120 次/分钟。

### 验收标准

- cooldown 阶段评论请求被拒绝。
- 回复必须继承父评论阵营。

## F03 通用点赞能力

### 接口定义

- 接口名：Like / Unlike / QueryUserLikeState
- 调用方向：PKHeatService -> UserLikeService
- 调用方式：进程内服务调用

### 输入参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | int64 | 是 | 用户ID |
| entityType | string | 是 | comment |
| entityId | int64 | 是 | 评论ID |

### 输出参数

| 字段 | 类型 | 说明 |
|------|------|------|
| liked | bool | 是否已点赞 |
| likeCount | int64 | 点赞总数 |

### 错误码

| 错误码 | 触发条件 |
|--------|----------|
| LIKE_409_DUP | 重复点赞 |
| LIKE_404_ENTITY | 目标评论不存在 |
| LIKE_500_INTERNAL | 点赞写入失败 |

### 固定策略

- 超时：200ms。
- 重试：最多 1 次，间隔 30ms，仅查询接口可重试。
- 熔断：30 秒窗口内错误率 >= 35% 且请求数 >= 40 时打开，保持 20 秒。
- 并发：单实例最大 300 并发调用。
- 限速：用户维度 120 次/分钟。

### 验收标准

- 点赞事件可在 1 秒内反映到热度计算。

## F04 内容反垃圾校验

### 接口定义

- 接口名：CheckComment
- 调用方向：PKCommentService -> SpamService
- 调用方式：进程内服务调用

### 输入参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | int64 | 是 | 用户ID |
| content | string | 是 | 文本内容 |
| ip | string | 是 | 用户IP |
| userAgent | string | 是 | 设备标识 |

### 输出参数

| 字段 | 类型 | 说明 |
|------|------|------|
| pass | bool | 是否通过 |
| reason | string | 拒绝原因 |
| riskScore | float64 | 风险分 |

### 错误码

| 错误码 | 触发条件 |
|--------|----------|
| SPAM_403_BLOCKED | 命中黑词或频率规则 |
| SPAM_429_RATE_LIMIT | 触发频率限制 |
| SPAM_500_INTERNAL | 校验服务异常 |

### 固定策略

- 超时：150ms。
- 重试：0 次，避免重复放行。
- 熔断：60 秒窗口内错误率 >= 50% 且请求数 >= 20 时打开，保持 30 秒。
- 并发：单实例最大 400 并发调用。
- 限速：用户维度 20 次/分钟，IP 维度 60 次/分钟。

### 验收标准

- 命中黑词内容必须 100% 拒绝。
- 频率超限请求必须返回 429。

## F05 定时任务调度

### 接口定义

- 接口名：RegisterCron / ExecuteTick
- 调用方向：PKService -> Scheduler
- 调用方式：进程内框架调用

### 输入参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| jobName | string | 是 | 任务名：pk_round_tick |
| cronExpr | string | 是 | 表达式：*/1 * * * * |
| lockKey | string | 是 | 分布式锁键 |

### 输出参数

| 字段 | 类型 | 说明 |
|------|------|------|
| runId | string | 本次执行ID |
| success | bool | 是否成功 |
| durationMs | int64 | 执行耗时 |

### 错误码

| 错误码 | 触发条件 |
|--------|----------|
| SCHED_409_LOCKED | 分布式锁被占用 |
| SCHED_504_TIMEOUT | 单次执行超时 |
| SCHED_500_INTERNAL | 调度执行异常 |

### 固定策略

- 超时：单次执行 5s。
- 重试：失败后 1 次重试，间隔 200ms。
- 熔断：连续 5 次失败后暂停 2 分钟。
- 并发：同一 jobName 全局并发=1。
- 限速：每分钟固定 1 次。

### 验收标准

- 任一回合状态推进最多延迟 60 秒。
- 同一回合不会出现重复结算记录。
