# 依赖外部特性详情

本文档采用确定性接口描述。每个特性均给出接口名、输入、输出、错误码和时效约束。

## 1. EXT-01 虎扑资讯列表抓取接口

### 1.1 接口定义

- 接口名：FetchHupuNewsList
- 调用方向：采集任务服务 -> 外部页面适配器
- 调用方式：HTTP GET
- 目标地址：
	- https://www.hupu.com/
	- https://bbs.hupu.com/

### 1.2 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| source | string | 是 | 固定为 hupu |
| pageCursor | string | 否 | 分页游标，为空表示首页抓取 |
| batchSize | int | 是 | 单次抓取条数，范围 1-200 |

### 1.3 输出参数

| 字段 | 类型 | 说明 |
|------|------|------|
| items | array | 资讯列表 |
| items[].title | string | 标题 |
| items[].url | string | 原文 URL |
| items[].coverUrl | string | 封面图 URL |
| items[].channel | string | 来源频道 |
| items[].publishedAt | int64 | 发布时间（秒级时间戳） |
| items[].interactions | object | 互动数据，包含亮数和回复数 |
| nextCursor | string | 下一页游标，无则返回空 |

### 1.4 错误码

- EXT_LIST_TIMEOUT：外部请求超时
- EXT_LIST_HTTP_4XX：外部返回 4xx
- EXT_LIST_HTTP_5XX：外部返回 5xx
- EXT_LIST_PARSE_FAILED：页面解析失败

### 1.5 时效与重试

- 超时：5 秒
- 最大重试：3 次
- 退避：30 秒、60 秒、120 秒
- 并发限制：单域名最多 2 并发

## 2. EXT-02 虎扑资讯详情补采接口

### 2.1 接口定义

- 接口名：FetchHupuNewsDetail
- 调用方向：采集任务服务 -> 外部页面适配器
- 调用方式：HTTP GET
- 目标地址：资讯详情页 URL（来源于 EXT-01 输出）

### 2.2 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| source | string | 是 | 固定为 hupu |
| articleUrl | string | 是 | 资讯原文 URL |
| sourceId | string | 否 | 外部唯一标识 |

### 2.3 输出参数

| 字段 | 类型 | 说明 |
|------|------|------|
| title | string | 标题 |
| summary | string | 摘要 |
| content | string | 正文 |
| coverUrl | string | 封面图 |
| author | string | 作者或来源作者 |
| publishedAt | int64 | 发布时间（秒级时间戳） |

### 2.4 错误码

- EXT_DETAIL_TIMEOUT：外部请求超时
- EXT_DETAIL_NOT_FOUND：详情页不存在
- EXT_DETAIL_PARSE_FAILED：详情解析失败

### 2.5 失败处理

- 连续失败 3 次后，将该资讯标记 detail_status=failed。
- detail_status=failed 的资讯在 24 小时内不再自动补采。

## 3. EXT-03 外部唯一键映射接口

### 3.1 接口定义

- 接口名：BuildExternalUniqueKey
- 调用方向：采集任务服务 -> 映射规则引擎
- 调用方式：函数调用

### 3.2 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| source | string | 是 | 固定为 hupu |
| url | string | 是 | 原文 URL |
| title | string | 否 | 标题 |
| publishedAt | int64 | 否 | 发布时间 |

### 3.3 输出参数

| 字段 | 类型 | 说明 |
|------|------|------|
| sourceId | string | 外部唯一键 |
| dedupKey | string | 去重键 |
| keyStrategy | string | 命中策略：source_id/url_hash/title_time |

### 3.4 规则

- URL 命中 bbs.hupu.com/{id}.html 时，sourceId 取该 id。
- URL 不含数字 id 时，sourceId 使用 canonical_url_hash。
- dedupKey 固定为 source + sourceId。

## 4. EXT-04 外部字段解析接口

### 4.1 接口定义

- 接口名：ParseHupuPayload
- 调用方向：采集任务服务 -> 多版本解析器
- 调用方式：函数调用

### 4.2 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| rawBody | string | 是 | 页面原始内容 |
| scene | string | 是 | list 或 detail |

### 4.3 输出参数

| 字段 | 类型 | 说明 |
|------|------|------|
| parsed | object | 解析后的统一结构 |
| parserVersion | string | 命中的解析器版本 |
| missingFields | array | 缺失字段列表 |

### 4.4 错误码

- EXT_PARSE_SCHEMA_CHANGED：结构漂移
- EXT_PARSE_REQUIRED_FIELD_MISSING：关键字段缺失

### 4.5 约束

- 标题、URL、发布时间是必需字段。
- 关键字段缺失率在 10 分钟窗口内超过 5% 触发告警。

## 5. EXT-05 外部源健康检查接口

### 5.1 接口定义

- 接口名：CheckHupuSourceHealth
- 调用方向：监控任务服务 -> 外部站点探针
- 调用方式：定时任务（每 1 分钟）

### 5.2 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| source | string | 是 | 固定为 hupu |
| windowMinutes | int | 是 | 固定为 10 |

### 5.3 输出参数

| 字段 | 类型 | 说明 |
|------|------|------|
| reachability | float | 可达率 |
| avgLatencyMs | int | 平均响应时延 |
| parseSuccessRate | float | 解析成功率 |
| newItemCount | int | 去重后新增条数 |

### 5.4 告警阈值

- 连续 3 个批次采集失败：P1
- parseSuccessRate < 95%（10 分钟窗口）：P1
- reachability < 98%（10 分钟窗口）：P2

## 6. EXT-06 外部失败重试与熔断接口

### 6.1 接口定义

- 接口名：ExecuteWithRetryAndCircuitBreaker
- 调用方向：采集任务服务 -> 重试与熔断组件
- 调用方式：函数调用

### 6.2 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| source | string | 是 | 固定为 hupu |
| operation | string | 是 | list/detail |
| taskId | int64 | 是 | 任务 ID |

### 6.3 输出参数

| 字段 | 类型 | 说明 |
|------|------|------|
| finalStatus | string | success/failed/circuit_open |
| retryCount | int | 实际重试次数 |
| nextRetryAt | int64 | 下次重试时间 |

### 6.4 固定策略

- 仅对 timeout、429、5xx 重试。
- 最大重试 3 次，退避 30/60/120 秒。
- 熔断阈值：连续 3 个批次失败。
- 熔断时长：15 分钟。
- 熔断打开期间返回 finalStatus=circuit_open。

## 7. 统一验收标准

- 外部源不可用连续 30 分钟时，资讯列表和详情接口可用率不低于 99.9%。
- 结构漂移后 24 小时内完成解析器修复并恢复采集。
- EXT-01 至 EXT-06 的调用日志必须包含 taskId、errorCode、retryCount、latencyMs。
