# 接口

## 1. 资讯列表

- `GET /api/news/list`

### 约束

- 认证：匿名可访问。
- 数据源：仅查询站内已采集数据，不实时请求外部站点。
- 默认排序：`publishedAt_desc`。

### 请求参数

- `page`：int，默认 1
- `pageSize`：int，默认 20，最大 200
- `q`：string，可选，关键词
- `category`：string，可选，分类 key
- `tag`：string，可选，标签 key
- `source`：string，可选，默认 `hupu`
- `sort`：string，可选
  - `publishedAt_desc`（默认）
  - `hotScore_desc`

### 参数校验

- `page < 1` 时按 1 处理。
- `pageSize <= 0` 时按 20 处理。
- `pageSize > 200` 时按 200 处理。
- `source` 仅允许 `hupu`，否则返回 `PARAM_INVALID`。

### 返回值

- `list[]`
  - `id`：资讯主键 ID
  - `title`：资讯标题
  - `summary`：资讯摘要
  - `coverUrl`：封面图 URL
  - `source`：来源标识（如 `hupu`）
  - `sourceName`：来源展示名称
  - `sourceUrl`：原文链接
  - `channel`：来源频道/分区
  - `category`：站内归一化分类 key
  - `tags`：标签列表
  - `publishedAt`：外部发布时间
  - `hotScore`：热度分值（用于热门排序）
- `count`：总条数
- `page`：当前页码
- `pageSize`：每页条数

### 成功示例

```json
{
  "list": [
    {
      "id": 1024,
      "title": "[流言板]示例资讯标题",
      "summary": "示例摘要",
      "coverUrl": "https://img.example.com/cover.jpg",
      "source": "hupu",
      "sourceName": "虎扑",
      "sourceUrl": "https://bbs.hupu.com/639689823.html",
      "channel": "国际足球资讯",
      "category": "soccer",
      "tags": ["转会", "曼联"],
      "publishedAt": 1748850000,
      "hotScore": 87
    }
  ],
  "count": 1,
  "page": 1,
  "pageSize": 20
}
```

## 2. 资讯详情

- `GET /api/news/detail`

### 约束

- 认证：匿名可访问。
- 查询方式：`id`、`sourceId`、`slug` 三者至少提供 1 个。
- 优先级：`id > sourceId > slug`。
- 当传入多个参数时，按优先级只使用最高优先级参数，其余忽略。

### 请求参数

- `id`：int64，可选
- `sourceId`：string，可选
- `slug`：string，可选

### 参数校验

- `id` 必须为正整数。
- `sourceId` 最大长度 64。
- `slug` 最大长度 128。
- 三个参数都为空时返回 `PARAM_INVALID`。

### 返回值

- `news`
  - `id`：资讯主键 ID
  - `source`：来源标识（如 `hupu`）
  - `sourceId`：外部唯一标识（如帖号）
  - `sourceUrl`：原文链接
  - `title`：资讯标题
  - `summary`：资讯摘要
  - `content`：资讯正文
  - `coverUrl`：封面图 URL
  - `sourceName`：来源展示名称
  - `channel`：来源频道/分区
  - `category`：站内归一化分类 key
  - `tags`：标签列表
  - `publishedAt`：外部发布时间
  - `fetchedAt`：站内抓取时间
  - `hotScore`：热度分值

### 成功示例

```json
{
  "news": {
    "id": 1024,
    "source": "hupu",
    "sourceId": "639689823",
    "sourceUrl": "https://bbs.hupu.com/639689823.html",
    "title": "[流言板]示例资讯标题",
    "summary": "示例摘要",
    "content": "示例正文内容",
    "coverUrl": "https://img.example.com/cover.jpg",
    "sourceName": "虎扑",
    "channel": "国际足球资讯",
    "category": "soccer",
    "tags": ["转会", "曼联"],
    "publishedAt": 1748850000,
    "fetchedAt": 1748850300,
    "hotScore": 87
  }
}
```

## 3. 分类与搜索

- `GET /api/news/categories`
- `GET /api/news/tags`
- `GET /api/news/search`

### 约束

- 认证：匿名可访问。
- `search` 与 `list` 使用一致的分页与排序校验规则。

### 搜索参数

- `q`：string，关键词
- `category`：string，可选
- `tag`：string，可选
- `page`：int，默认 1
- `pageSize`：int，默认 20，最大 200

### `GET /api/news/categories` 返回示例

```json
{
  "list": [
    {"key": "nba", "name": "NBA", "sort": 10},
    {"key": "soccer", "name": "足球", "sort": 20}
  ]
}
```

### `GET /api/news/tags` 返回示例

```json
{
  "list": [
    {"key": "transfer", "name": "转会"},
    {"key": "match", "name": "比赛"}
  ]
}
```

## 4. 后台采集接口

- `POST /api/admin/news/crawl/run`：触发一次采集
  - 认证：必须登录且具备管理员权限。
  - 请求体：`{"source":"hupu","taskType":"list","limit":50}`
  - 参数说明：`taskType` 允许 `list`；`limit` 取值 1-200。
- `POST /api/admin/news/crawl/refresh`：触发详情补采
  - 认证：必须登录且具备管理员权限。
  - 请求体：`{"source":"hupu","articleIds":[1024,1025]}`
  - 参数说明：`articleIds` 长度 1-200。
- `GET /api/admin/news/crawl/tasks`：查看任务状态
  - 认证：必须登录且具备管理员权限。
  - 查询参数：`status`、`page`、`pageSize`。
- `GET /api/admin/news/crawl/logs`：查看失败日志
  - 认证：必须登录且具备管理员权限。
  - 查询参数：`taskId`、`page`、`pageSize`。

### 后台接口成功返回结构

```json
{
  "taskId": 20260603001,
  "status": "pending"
}
```

## 5. 错误码

- `NEWS_NOT_FOUND`：资讯不存在
- `NEWS_DISABLED`：资讯功能未启用
- `NEWS_SOURCE_DISABLED`：来源未启用
- `NEWS_CRAWL_FAILED`：采集失败
- `PARAM_INVALID`：参数错误
- `NOT_LOGIN`：未登录
- `NO_PERMISSION`：无管理员权限

## 6. HTTP 状态码约定

- `200`：请求成功。
- `400`：参数错误（`PARAM_INVALID`）。
- `401`：未登录（`NOT_LOGIN`）。
- `403`：无权限（`NO_PERMISSION`）。
- `404`：资源不存在（`NEWS_NOT_FOUND`）。
- `500`：服务内部错误。
