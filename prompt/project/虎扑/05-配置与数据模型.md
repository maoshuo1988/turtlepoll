# 配置与数据模型

## 1. 采集配置

```yaml
news:
  enabled: true
  source: hupu
  baseURL: "https://www.hupu.com"
  bbsBaseURL: "https://bbs.hupu.com"
  cronSpec: "*/10 * * * *"
  batchSize: 50
  requestTimeoutSeconds: 5
  maxQPSPerWorker: 1
  maxConcurrencyPerDomain: 2
  maxRetry: 3
  retryBaseSeconds: 60
  retryMaxSeconds: 120
  circuitBreakMinutes: 15
  allowDetailRefresh: true
  allowListHot: true
  allowSearch: true
```

### 1.1 配置语义

- `enabled`：是否启用资讯采集。
- `source`：数据源标识，当前固定为 `hupu`。
- `baseURL`：虎扑首页基础地址。
- `bbsBaseURL`：虎扑资讯帖基础地址。
- `cronSpec`：定时采集表达式。
- `batchSize`：每次拉取条数。
- `requestTimeoutSeconds`：单次请求超时秒数。
- `maxQPSPerWorker`：单 worker 的请求速率上限。
- `maxConcurrencyPerDomain`：单域名并发上限。
- `maxRetry`：单批次连续失败阈值。
- `retryBaseSeconds`：失败退避基数。
- `retryMaxSeconds`：退避最大秒数。
- `circuitBreakMinutes`：连续失败后的熔断时长（分钟）。
- `allowDetailRefresh`：是否允许补采详情。
- `allowListHot`：是否允许热门列表接口。
- `allowSearch`：是否允许搜索接口。

## 2. 资讯主表

### 2.1 `t_news_article`

| 字段 | 类型 | 可空 | 默认值 | 说明 |
|------|------|------|------|------|
| `id` | bigint | 否 | 自增 | 主键 |
| `source` | varchar(16) | 否 | `hupu` | 数据源 |
| `source_id` | varchar(64) | 否 | - | 外部唯一键 |
| `source_url` | varchar(512) | 否 | - | 原文链接 |
| `slug` | varchar(128) | 是 | null | 可读别名 |
| `title` | varchar(255) | 否 | - | 标题 |
| `summary` | text | 是 | null | 摘要 |
| `content` | longtext | 是 | null | 正文 |
| `cover_url` | varchar(512) | 是 | null | 封面图 |
| `channel` | varchar(64) | 是 | null | 来源频道 |
| `category` | varchar(64) | 否 | `general` | 归一化分类 |
| `tags` | json | 否 | `[]` | 标签数组 |
| `published_at` | bigint | 否 | 0 | 外部发布时间（秒级时间戳） |
| `fetched_at` | bigint | 否 | 0 | 抓取时间（秒级时间戳） |
| `hot_score` | int | 否 | 0 | 热度分值 |
| `detail_status` | varchar(16) | 否 | `pending` | pending/success/failed |
| `status` | varchar(16) | 否 | `normal` | normal/hidden/deleted |
| `created_at` | bigint | 否 | 0 | 创建时间 |
| `updated_at` | bigint | 否 | 0 | 更新时间 |

### 2.2 约束

- `source + source_id` 唯一。
- `source_url` 建立普通索引。
- `slug` 建立唯一索引（允许空）。
- `published_at` 用于排序与时间筛选。
- `category + published_at` 建立联合索引。
- `status + published_at` 建立联合索引。
- `hot_score` 初版按规则实时计算并落库。

## 3. 来源表

### 3.1 `t_news_source`

| 字段 | 类型 | 可空 | 默认值 | 说明 |
|------|------|------|------|------|
| `id` | bigint | 否 | 自增 | 主键 |
| `source_key` | varchar(16) | 否 | - | `hupu` |
| `name` | varchar(32) | 否 | - | 来源展示名 |
| `base_url` | varchar(255) | 否 | - | 来源基址 |
| `enabled` | tinyint | 否 | 1 | 是否启用 |
| `created_at` | bigint | 否 | 0 | 创建时间 |
| `updated_at` | bigint | 否 | 0 | 更新时间 |

## 4. 分类与标签

### 4.1 `t_news_category`

| 字段 | 说明 |
|------|------|
| `id` | 主键 |
| `category_key` | 归一化分类 key |
| `name` | 分类名 |
| `parent_id` | 父分类，可空 |
| `sort` | 排序 |
| `enabled` | 是否启用 |

### 4.2 `t_news_tag`

| 字段 | 说明 |
|------|------|
| `id` | 主键 |
| `tag_key` | 标签 key |
| `name` | 标签名 |
| `enabled` | 是否启用 |

### 4.3 关联表

- `t_news_article_category`
- `t_news_article_tag`

### 4.4 关联表约束

- `t_news_article_category` 唯一键：`article_id + category_id`。
- `t_news_article_tag` 唯一键：`article_id + tag_id`。
- 两张关联表都需建立 `article_id` 普通索引。

## 5. 采集任务表

### 5.1 `t_news_crawl_task`

| 字段 | 类型 | 可空 | 默认值 | 说明 |
|------|------|------|------|------|
| `id` | bigint | 否 | 自增 | 主键 |
| `source` | varchar(16) | 否 | `hupu` | 数据源 |
| `task_type` | varchar(16) | 否 | `list` | list/detail/refresh |
| `cursor` | varchar(255) | 是 | null | 游标或分页位置 |
| `status` | varchar(16) | 否 | `pending` | pending/running/success/failed |
| `fail_count` | int | 否 | 0 | 失败次数 |
| `retry_after` | bigint | 否 | 0 | 下次重试时间戳 |
| `last_error` | text | 是 | null | 最近错误 |
| `started_at` | bigint | 否 | 0 | 开始时间 |
| `finished_at` | bigint | 否 | 0 | 结束时间 |
| `created_at` | bigint | 否 | 0 | 创建时间 |
| `updated_at` | bigint | 否 | 0 | 更新时间 |

### 5.2 任务索引

- `status + created_at` 联合索引。
- `source + task_type + created_at` 联合索引。
- `retry_after` 普通索引。

## 6. 状态定义

- `status=normal`：正常可见。
- `status=hidden`：可采集但前台不展示。
- `status=deleted`：逻辑删除。
- `detail_status=pending`：待补采。
- `detail_status=success`：补采成功。
- `detail_status=failed`：补采失败。
