# 撕裂带流程图

## 1. 热度计算主状态机

说明: 热度计算状态机独立设计，不复用其他模块状态机实现。

```mermaid
flowchart TD
    A["INIT: 实体已创建"] --> B["COLLECTING: 接收计分输入"]
    B --> C["FROZEN: 冻结热度快照"]
    C --> D["SETTLED: 下游消费并归档"]
```

## 2. 热度计算状态机与对立PK映射

```mermaid
flowchart TD
    A["PK betting"] --> B["Heat COLLECTING"]
    C["PK locked"] --> B
    D["PK settle_ready + endTime reached"] --> E["Heat FROZEN"]
    F["PK settled"] --> G["Heat SETTLED"]
```

## 3. 热度计算状态机与暗盘映射

```mermaid
flowchart TD
    A["Dark NOT_OPEN"] --> B["Heat INIT"]
    C["Dark OPEN"] --> D["Heat COLLECTING"]
    E["Dark CLOSED"] --> D
    F["Dark SETTLED"] --> G["Heat FROZEN"]
    H["Dark TEAR_SETTLED"] --> I["Heat SETTLED"]
```

## 4. 锁边建立与覆盖

说明: 锁边分为强锁边和弱锁边，强锁边优先级高于弱锁边，且强锁边可以覆盖同一用户同一目标上的弱锁边。

```mermaid
flowchart TD
    A["收到互动请求"] --> B{"是否已有强锁边"}
    B -- "否" --> C{"是否已有弱锁边"}
    C -- "否" --> D["建立弱锁边 INTERACT"]
    C -- "是且选项一致" --> E["保持弱锁边"]
    C -- "是且选项冲突" --> F["拒绝请求 TEAR_CAMP_CONFLICT"]
    B -- "是且选项一致" --> G["保持强锁边 BET"]
    B -- "是且选项冲突" --> H["拒绝请求 TEAR_CAMP_LOCKED_BY_BET"]
    D --> I["继续写评论/回复/点赞"]
    E --> I
    G --> I
```

## 5. 强锁边覆盖弱锁边

```mermaid
flowchart TD
    A["用户先建立弱锁边 INTERACT"] --> B["后续发生下注 BET"]
    B --> C{"下注 option 是否与弱锁边一致"}
    C -- "是" --> D["将锁边升级为 BET"]
    C -- "否" --> E["用 BET 覆盖原弱锁边并按 BET 口径判定"]
    D --> F["后续互动按强锁边处理"]
    E --> F
    F --> G{"后续互动 option 是否与 BET 一致"}
    G -- "是" --> H["允许"]
    G -- "否" --> I["拒绝 TEAR_CAMP_LOCKED_BY_BET"]
```

## 6. 热度计算流程

```mermaid
flowchart LR
    A["点赞事件"] --> B["累计 H_like = Σ1"]
    C["评论/回复"] --> D["固定参数：A/U/T/C = 1"]
    D --> E["计算 Base：Base = 3"]
    E --> F["计算对数增益：log&#40;1 + L&#41;"]
    F --> G["累计 H_comment = Σ min&#40;Base × &#40;1 + log&#40;1 + L&#41;&#41;, 20&#41;"]
    H["下注金额"] --> I["累计 BetAmount"]
    I --> J["计算 H_coin = BetAmount × 0.02"]
    B --> K["汇总 Heat_total = H_like + H_comment + H_coin"]
    G --> K
    J --> K
```
