# 撕裂带配置与数据模型

## 1. 核心配置

| 配置键 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| tear.enabled | bool | true | 是否启用撕裂带 |
| tear.dark.close_countdown_seconds | int | 60 | 暗盘封盘前冷静期 |
| tear.dark.mint_ratio | float | 0.1 | 暗盘撕裂带池铸币比例 |
| tear.dark.mint_floor | int | 10 | 暗盘撕裂带池铸币下限 |
| tear.round.duration_seconds | int | 259200 | 开撕台单局时长(72h) |
| tear.round.cooldown_seconds | int | 600 | 对立PK业务冷却期(10m)，不作为热度冻结触发条件 |
| tear.heat.comment_cap | int | 20 | 单条评论热度上限 |
| tear.heat.coin_factor | float | 0.02 | 投币热度系数 |
| tear.settle.retry_max | int | 3 | 结算任务最大重试次数 |

## 2. 数据模型

### 2.1 t_tear_event

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint PK | 事件ID |
| scene_type | varchar(16) | `DARK`/`ARENA` |
| biz_id | bigint | 业务事件ID（暗盘事件ID或对立PK回合ID） |
| title | varchar(128) | 事件标题 |
| option_a_name | varchar(64) | A下注对象名称 |
| option_b_name | varchar(64) | B下注对象名称 |
| option_c_name | varchar(64) | C下注对象名称(三元市场可选) |
| status | varchar(16) | 状态 |
| open_time | bigint | 开放时间(秒) |
| close_time | bigint | 封盘时间(秒) |
| settle_time | bigint | 结算时间(秒) |
| round_no | int | 开撕台回合号 |
| season_no | int | 开撕台赛季号 |
| create_time | bigint | 创建时间 |
| update_time | bigint | 更新时间 |

索引:

- `idx_scene_status(scene_type,status)`
- `uk_scene_biz(scene_type,biz_id,round_no)`

### 2.2 t_tear_camp_member

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint PK | 主键 |
| event_id | bigint | 事件ID |
| user_id | bigint | 用户ID |
| option | varchar(8) | `A`/`B`/`C` |
| lock_type | varchar(16) | `BET`/`INTERACT` |
| first_action_time | bigint | 首次锁定时间 |
| create_time | bigint | 创建时间 |
| update_time | bigint | 更新时间 |

索引:

- `uk_event_user(event_id,user_id)`

### 2.3 t_tear_heat_snapshot

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint PK | 主键 |
| event_id | bigint | 事件ID |
| option | varchar(8) | `A`/`B`/`C` |
| h_like | decimal(18,6) | 点赞热度 |
| h_comment | decimal(18,6) | 评论热度 |
| h_coin | decimal(18,6) | 投币热度 |
| h_total | decimal(18,6) | 总热度 |
| snapshot_time | bigint | 快照时间 |
| snapshot_type | varchar(16) | `SETTLE`/`CHECKPOINT` |
| freeze_source | varchar(16) | `ON_DEMAND`/`SCHEDULER` |

索引:

- `idx_event_snapshot(event_id,snapshot_time)`
- `uk_event_settle_snapshot(event_id,snapshot_type)`，其中 `snapshot_type=SETTLE` 时唯一

### 2.4 t_tear_settle_batch

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint PK | 批次ID |
| event_id | bigint | 事件ID |
| settle_type | varchar(16) | `ARENA`/`PREDICT_MARKET`（历史兼容值：`DARK_REALTIME`/`DARK_TEAR`） |
| settle_version | int | 结算版本 |
| winner_option | varchar(8) | 胜方下注对象 |
| pool_amount | bigint | 本批次奖池 |
| status | varchar(16) | `INIT`/`SUCCESS`/`FAILED` |
| retry_count | int | 重试次数 |
| create_time | bigint | 创建时间 |
| update_time | bigint | 更新时间 |

索引:

- `uk_settle_idem(event_id,settle_type,settle_version)`

### 2.5 t_tear_reward_log

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint PK | 主键 |
| settle_batch_id | bigint | 结算批次 |
| event_id | bigint | 事件ID |
| user_id | bigint | 用户ID |
| option | varchar(8) | 用户下注对象 |
| reward_type | varchar(16) | 奖励类型 |
| reward_amount | bigint | 奖励金额 |
| heat_snapshot | decimal(18,6) | 用户热度快照 |
| tx_id | bigint | 币流水ID |
| create_time | bigint | 创建时间 |

索引:

- `idx_event_user(event_id,user_id)`
- `idx_settle_batch(settle_batch_id)`

### 2.6 t_tear_interact_log

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint PK | 主键 |
| event_id | bigint | 事件ID |
| user_id | bigint | 用户ID |
| option_at_action | varchar(8) | 互动发生时所属下注对象 `A/B/C` |
| action_type | varchar(16) | `COMMENT`/`REPLY` |
| target_comment_id | bigint | 回复目标评论ID，顶层评论为0 |
| content_id | bigint | 评论或回复ID |
| received_like_count | bigint | 当前累计收到点赞数 |
| create_time | bigint | 创建时间 |

索引:

- `idx_event_user_action(event_id,user_id,action_type)`
- `idx_event_option(event_id,option_at_action)`

### 2.7 t_tear_user_event_stat

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint PK | 主键 |
| event_id | bigint | 事件ID |
| user_id | bigint | 用户ID |
| my_option | varchar(8) | 当前下注对象 `A/B/C` |
| received_like_count | bigint | 收到点赞总数 |
| my_comment_count | bigint | 评论与回复总条数 |
| my_bet_amount | bigint | 累计下注额 |
| estimated_payout | bigint | 预计获得派奖 |
| my_like_heat | decimal(18,6) | 点赞热度分项 |
| my_comment_heat | decimal(18,6) | 评论热度分项 |
| my_coin_heat | decimal(18,6) | 投币热度分项 |
| my_total_heat | decimal(18,6) | 总热度 |
| update_time | bigint | 更新时间 |

索引:

- `uk_event_user_stat(event_id,user_id)`
- `idx_event_option_rank(event_id,my_option,my_total_heat)`
