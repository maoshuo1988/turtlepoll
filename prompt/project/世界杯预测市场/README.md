## 核心口径

- 小组赛：`marketType=1x2`，下注选项为 `A/B/DRAW`。
- 淘汰赛：`marketType=binary`，下注选项为 `A/B`。
- 小组赛平局：写入 `PredictMarket.result=DRAW`，下注 `DRAW` 的用户赢。
- 淘汰赛平局：记录错误日志，不自动退款、不自动派奖，交运营人员结算。
- 主客队一旦确定，后续同步不再覆盖主客队身份字段。
- 同步流程不覆盖运营字段：上下文说明、封面图、热度、参与人数。
