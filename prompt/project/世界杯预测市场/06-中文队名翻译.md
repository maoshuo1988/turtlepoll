## 10. 中文队名与国家翻译

### 10.1 翻译目标

参赛国家/队伍名称统一展示中文，例如：

```text
Argentina -> 阿根廷
France -> 法国
United States -> 美国
England -> 英格兰
```

所有同步生成的展示文案应使用中文队名：

```text
PredictMarket.title = 阿根廷 vs 法国
PredictContext.eventName = 阿根廷 vs 法国
PredictContext.proText = 阿根廷 胜
PredictContext.conText = 法国 胜
```

### 10.2 翻译策略

已新增静态映射表，优先按 football-data `team.id` 映射，其次按英文名称和常见别名映射：

```go
var footballTeamZhNameByID = map[int64]string{
    // football-data team id -> 中文名
}

var footballTeamZhNameByName = map[string]string{
    "Argentina": "阿根廷",
    "France": "法国",
}
```

翻译函数：

```go
func translateFootballTeamName(teamID int64, name string) string {
    if zh := footballTeamZhNameByID[teamID]; zh != "" {
        return zh
    }
    if zh := footballTeamZhNameByName[strings.TrimSpace(name)]; zh != "" {
        return zh
    }
    return strings.TrimSpace(name)
}
```

### 10.3 翻译写入位置

同步时先拿外部原始值：

```text
m.HomeTeam.ID
m.HomeTeam.Name
m.AwayTeam.ID
m.AwayTeam.Name
```

再翻译为站内展示值：

```text
homeTeamName := translateFootballTeamName(m.HomeTeam.ID, m.HomeTeam.Name)
awayTeamName := translateFootballTeamName(m.AwayTeam.ID, m.AwayTeam.Name)
```

站内 `MatchSchedule.homeTeam/awayTeam`、`PredictMarket.title`、`PredictContext.proText/conText` 都使用中文名。

是否保留英文原名：

- 短期可以不加字段。
- 如果后续需要审计，建议新增 `homeTeamRaw/awayTeamRaw`。
