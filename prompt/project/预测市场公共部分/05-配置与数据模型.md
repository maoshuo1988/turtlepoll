# 预测市场公共部分配置与数据模型

## 1. 配置

公共下注与结算 P0 不新增独立配置。热度口径与阈值统一由 [撕裂带热度计算](../撕裂带热度计算/05-配置与数据模型-0.md) 维护。

用户战绩和余额榜建议新增配置：

| 配置 | 默认值 | 说明 |
|------|--------|------|
| `predict.leaderboard.defaultLimit` | `20` | 余额榜默认返回数量 |
| `predict.leaderboard.maxLimit` | `100` | 余额榜最大返回数量 |
| `predict.commentReward.enabled` | `true` | 是否启用开撕台评论奖励 |
| `predict.commentReward.bonusPool` | `100` | 开撕台评论奖励奖金池基数 |
| `predict.commentReward.multiplier` | `10` | 奖励公式固定乘数 |
| `predict.commentReward.deadlineSeconds` | `3600` | 市场结算后奖励发放窗口 |
| `predict.commentReward.cronSpec` | `* * * * *` | 奖励任务扫描周期 |

来源配置保留在专项文档：

- 世界杯：`footballData`
- Polymarket：`polymarket`

## 2. PredictMarket

作用：统一市场主记录。

关键字段：

| 字段 | 说明 |
|------|------|
| `sourceModel` | 来源模型，例如 `MatchSchedule` 或 `Polymarket` |
| `sourceModelId` | 来源模型 ID |
| `title` | 市场标题 |
| `marketType` | `binary` 或 `1x2` |
| `status` | `OPEN/CLOSED/SETTLED` |
| `closeTime` | 下注截止时间 |
| `result` | 最终结果 `A/B/DRAW` |
| `baseA/baseB/baseDraw` | 虚拟底池 |
| `poolA/poolB/poolDraw` | 真实下注池 |

外部来源字段：

| 字段 | 说明 |
|------|------|
| `externalKey` | 外部业务 key |
| `resolved` | 外部是否已 resolved |
| `resolvedOutcomeId` | 外部结果 ID |
| `resolvedOutcomeName` | 外部结果展示名 |
| `resolvedAt` | 外部结果时间 |

公共结算以 `status/result` 为准，外部字段只作为同步和运营参考。

## 3. PredictContext

作用：统一展示上下文。

关键字段：

| 字段 | 说明 |
|------|------|
| `marketId` | 对应 `PredictMarket.Id` |
| `eventName` | 展示名称 |
| `proText/conText` | A/B 展示文案 |
| `imageUrl/listImage` | 图片 |
| `detail` | 详情 |
| `tags` | 逗号分隔标签 |
| `heat` | 热度，按撕裂带热度计算口径写入 |

同步约束：

- 来源同步可以创建上下文。
- 来源同步不应覆盖运营编辑字段。
- 来源同步不应覆盖 `heat`。

## 4. PredictBet

作用：统一下注单。

关键字段：

| 字段 | 说明 |
|------|------|
| `userId` | 用户 ID |
| `marketId` | 市场 ID |
| `option` | `A/B/DRAW` |
| `amount` | 下注金额 |

## 5. UserCoin 与 UserCoinLog

下注：

```text
UserCoin.balance -= amount
UserCoinLog.bizType = BET
UserCoinLog.amount < 0
```

结算派奖：

```text
UserCoin.balance += payout
UserCoinLog.bizType = SETTLE
UserCoinLog.amount > 0
```

退款预留：

```text
UserCoin.balance += refundAmount
UserCoinLog.bizType = REFUND
```

## 6. PredictUserStat

作用：用户预测市场战绩物化统计。

建议字段：

| 字段 | 说明 |
|------|------|
| `userId` | 用户 ID，唯一 |
| `settledMarketCount` | 已计入胜率的市场场数 |
| `winMarketCount` | 命中市场场数 |
| `loseMarketCount` | 未命中市场场数 |
| `winRate` | 胜率，可存小数或查询时计算 |
| `currentWinStreak` | 最新连胜场数 |
| `bestWinStreak` | 历史最高连胜，预留 |
| `lastSettledMarketId` | 最近计入战绩的市场 ID，便于排查 |
| `lastSettledAt` | 最近计入战绩时间 |
| `createTime/updateTime` | 创建和更新时间 |

约束：

```text
unique(user_id)
index(current_win_streak)
```

胜率可以不落库，查询时按 `winMarketCount / settledMarketCount` 计算。若落库，需要和计数字段同事务更新。

| 字段 | 说明 |
|------|------|

## 8. 账户余额榜查询模型

### 8.1 Top N 排序数据

排序来源：

| 数据 | 来源 |
|------|------|
| 用户 ID | `UserCoin.userId` |
| 余额 | `UserCoin.balance` |

推荐索引：

```text
index UserCoin(balance desc, user_id)
```

### 8.2 榜单展示聚合数据

| 数据 | 来源 |
|------|------|
| 余额 | `UserCoin.balance` |
| 用户名称 | `User.nickname` |
| 用户头像 | `User.avatar` |
| 胜率 | `PredictUserStat` |
| 最新连胜场数 | `PredictUserStat.currentWinStreak` |

推荐索引：

```text
index PredictUserStat(user_id)
```

### 8.3 我的排名摘要

我的排名按余额榜同一排序规则计算。

需要读取：

| 数据 | 来源 |
|------|------|
| 我的余额 | `UserCoin.balance` |
| 我的排名 | `UserCoin` 计数查询 |
| 我的胜率 | `PredictUserStat` |
| 我的最新连胜 | `PredictUserStat.currentWinStreak` |

排名公式：

```text
rank = count(balance greater than myBalance) + count(balance equals myBalance and userId less than myUserId) + 1
```

## 9. 赔率字段

二元市场：

```text
effA = baseA + poolA
effB = baseB + poolB
```

三元市场：

```text
effA = baseA + poolA
effB = baseB + poolB
effDraw = baseDraw + poolDraw
```

下注单保存锁定赔率，不在用户结算时重算。

## 10. PredictCommentMeta

作用：记录预测市场评论与回复在动作时刻绑定的预测选项。

建议字段：

| 字段 | 说明 |
|------|------|
| `commentId` | 评论或回复 ID，唯一 |
| `marketId` | 市场 ID |
| `userId` | 评论或回复用户 ID |
| `optionAtAction` | 动作时归属选项 `A/B/DRAW` |
| `parentCommentId` | 父评论 ID，一级评论为 0 |
| `actionType` | `comment/reply` |
| `createTime/updateTime` | 创建和更新时间 |

约束：

```text
unique(comment_id)
index(market_id, option_at_action)
index(market_id, user_id)
```

归属规则：

- 一级评论：必须提交 `option`，写入 `optionAtAction`。
- 回复评论：前端主协议不要求传 `option`；未锁边场景可选传 `option` 作为弱锁边输入。
- 回复评论 `optionAtAction` 推导顺序：用户锁边优先 -> 请求 `option`（仅未锁边）-> 父评论归属兜底。

## 11. PredictCampMember

作用：复用 PK 锁边模型，记录预测市场用户阵营锁定关系。

建议字段：

| 字段 | 说明 |
|------|------|
| `eventType` | 默认 `predict_market`（迁移期兼容读取 `pk` 历史数据） |
| `eventId` | 映射 `marketId` |
| `topicId` | 映射 `marketId` |
| `roundId` | 固定 `0` |
| `userId` | 用户 ID |
| `option` | 锁定选项 `A/B/DRAW` |
| `lockType` | `BET/INTERACT` |
| `firstActionTime` | 首次锁边时间 |
| `createTime/updateTime` | 创建和更新时间 |

约束：

```text
unique(event_type, topic_id, round_id, user_id)
index(event_id)
index(topic_id, option)
```

规则：

- 下注写入或升级为 `lockType=BET`。
- 评论/回复/点赞写入 `lockType=INTERACT`。
- 与已有锁边 `option` 冲突时，返回 `TEAR_CAMP_LOCKED_BY_BET` 或 `TEAR_CAMP_CONFLICT`。

## 12. PredictCommentRewardLog

作用：开撕台评论奖励批次审计。

建议字段：

| 字段 | 说明 |
|------|------|
| `marketId` | 市场 ID，唯一 |
| `winnerOption` | 获胜选项 |
| `bonusPool` | 奖金池，固定取单市场总池的 `10%` |
| `winnerTotalCommentHeat` | 胜方总评论热度 |
| `multiplier` | 奖励公式乘数，固定为 10 |
| `remainder` | 未发放余数 |
| `status` | `PENDING/PROCESSING/PAID/EXPIRED/FAILED` |
| `reason` | 失败、过期或无获奖用户原因 |
| `settledAt` | 市场结算时间 |
| `deadlineAt` | 发放截止时间 |
| `paidAt` | 完成发放时间 |
| `createTime/updateTime` | 创建和更新时间 |

约束：

```text
unique(market_id)
index(status, deadline_at)
```

奖金池规则：

```text
bonusPool = (poolA + poolB + poolDraw) * 10%
binary 市场下 poolDraw = 0
```

禁止项：

- 禁止使用全站池、活动池、配置常量池覆盖 `bonusPool`。

## 13. PredictCommentRewardItem

作用：开撕台评论奖励用户明细。

建议字段：

| 字段 | 说明 |
|------|------|
| `rewardLogId` | 奖励批次 ID |
| `marketId` | 市场 ID |
| `userId` | 获奖用户 ID |
| `amount` | 发放金额 |
| `userCommentHeat` | 该用户胜方评论热度 |
| `firstCommentId` | 该用户最早胜方评论或回复 ID |
| `coinLogId` | 对应 `UserCoinLog.id` |
| `createTime` | 创建时间 |

约束：

```text
unique(reward_log_id, user_id)
index(market_id, user_id)
```

金币流水：

```text
UserCoinLog.bizType = COMMENT_REWARD
UserCoinLog.bizId = PredictCommentRewardLog.id
```
