# 预测市场公共部分配置与数据模型

## 1. 配置

公共下注与结算 P0 不新增独立配置。

用户战绩和余额榜建议新增配置：

| 配置 | 默认值 | 说明 |
|------|--------|------|
| `predict.leaderboard.defaultLimit` | `20` | 余额榜默认返回数量 |
| `predict.leaderboard.maxLimit` | `100` | 余额榜最大返回数量 |

来源配置保留在专项文档：

- 世界杯：`footballData`
- Polymarket：`polymarket`

## 2. PredictMarket

作用：统一市场主记录。

关键字段：

| 字段 | 说明 |
|------|------|
| `sourceModel` | 来源模型，例如 `MatchSchedule` 或 `Polymarket` |
| `sourceModelId` | 来源模型 ID |
| `title` | 市场标题 |
| `marketType` | `binary` 或 `1x2` |
| `status` | `OPEN/CLOSED/SETTLED` |
| `closeTime` | 下注截止时间 |
| `result` | 最终结果 `A/B/DRAW` |
| `baseA/baseB/baseDraw` | 虚拟底池 |
| `poolA/poolB/poolDraw` | 真实下注池 |

外部来源字段：

| 字段 | 说明 |
|------|------|
| `externalKey` | 外部业务 key |
| `resolved` | 外部是否已 resolved |
| `resolvedOutcomeId` | 外部结果 ID |
| `resolvedOutcomeName` | 外部结果展示名 |
| `resolvedAt` | 外部结果时间 |

公共结算以 `status/result` 为准，外部字段只作为同步和运营参考。

## 3. PredictContext

作用：统一展示上下文。

关键字段：

| 字段 | 说明 |
|------|------|
| `marketId` | 对应 `PredictMarket.Id` |
| `eventName` | 展示名称 |
| `proText/conText` | A/B 展示文案 |
| `imageUrl/listImage` | 图片 |
| `detail` | 详情 |
| `tags` | 逗号分隔标签 |
| `heat` | 热度 |

同步约束：

- 来源同步可以创建上下文。
- 来源同步不应覆盖运营编辑字段。
- 来源同步不应覆盖 `heat`。

## 4. PredictBet

作用：统一下注单。

关键字段：

| 字段 | 说明 |
|------|------|
| `userId` | 用户 ID |
| `marketId` | 市场 ID |
| `option` | `A/B/DRAW` |
| `amount` | 下注金额 |
| `odds` | 下单时锁定赔率 |
| `effA/effB/effDraw` | 下单时有效池快照 |
| `status` | `OPEN/SETTLED/CANCELED` |
| `settleResult` | `WIN/LOSE` |
| `payout` | 派奖金额 |
| `settleTime` | 结算时间 |

## 5. UserCoin 与 UserCoinLog

下注：

```text
UserCoin.balance -= amount
UserCoinLog.bizType = BET
UserCoinLog.amount < 0
```

结算派奖：

```text
UserCoin.balance += payout
UserCoinLog.bizType = SETTLE
UserCoinLog.amount > 0
```

退款预留：

```text
UserCoin.balance += refundAmount
UserCoinLog.bizType = REFUND
```

## 6. PredictUserStat

作用：用户预测市场战绩物化统计。

建议字段：

| 字段 | 说明 |
|------|------|
| `userId` | 用户 ID，唯一 |
| `settledMarketCount` | 已计入胜率的市场场数 |
| `winMarketCount` | 命中市场场数 |
| `loseMarketCount` | 未命中市场场数 |
| `winRate` | 胜率，可存小数或查询时计算 |
| `currentWinStreak` | 最新连胜场数 |
| `bestWinStreak` | 历史最高连胜，预留 |
| `lastSettledMarketId` | 最近计入战绩的市场 ID，便于排查 |
| `lastSettledAt` | 最近计入战绩时间 |
| `createTime/updateTime` | 创建和更新时间 |

约束：

```text
unique(user_id)
index(current_win_streak)
```

胜率可以不落库，查询时按 `winMarketCount / settledMarketCount` 计算。若落库，需要和计数字段同事务更新。

## 7. PredictUserMarketStat

作用：用户单市场战绩明细，用于幂等控制和后续重算。

建议字段：

| 字段 | 说明 |
|------|------|
| `userId` | 用户 ID |
| `marketId` | 市场 ID |
| `result` | `WIN/LOSE/VOID` |
| `betAmount` | 该用户在该市场总下注额 |
| `payout` | 该用户在该市场总派奖额 |
| `settledBetCount` | 本次归并的下注单数量 |
| `settleTime` | 计入战绩时间 |
| `createTime/updateTime` | 创建和更新时间 |

约束：

```text
unique(user_id, market_id)
index(market_id)
index(user_id, settle_time)
```

## 8. 账户余额榜查询模型

### 8.1 Top N 排序数据

排序来源：

| 数据 | 来源 |
|------|------|
| 用户 ID | `UserCoin.userId` |
| 余额 | `UserCoin.balance` |

推荐索引：

```text
index UserCoin(balance desc, user_id)
```

### 8.2 榜单展示聚合数据

| 数据 | 来源 |
|------|------|
| 余额 | `UserCoin.balance` |
| 用户名称 | `User.nickname` |
| 用户头像 | `User.avatar` |
| 胜率 | `PredictUserStat` |
| 最新连胜场数 | `PredictUserStat.currentWinStreak` |

推荐索引：

```text
index PredictUserStat(user_id)
```

### 8.3 我的排名摘要

我的排名按余额榜同一排序规则计算。

需要读取：

| 数据 | 来源 |
|------|------|
| 我的余额 | `UserCoin.balance` |
| 我的排名 | `UserCoin` 计数查询 |
| 我的胜率 | `PredictUserStat` |
| 我的最新连胜 | `PredictUserStat.currentWinStreak` |

排名公式：

```text
rank = count(balance greater than myBalance) + count(balance equals myBalance and userId less than myUserId) + 1
```

## 9. 赔率字段

二元市场：

```text
effA = baseA + poolA
effB = baseB + poolB
```

三元市场：

```text
effA = baseA + poolA
effB = baseB + poolB
effDraw = baseDraw + poolDraw
```

下注单保存锁定赔率，不在用户结算时重算。
