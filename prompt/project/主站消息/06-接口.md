# 主站消息接口

## 0. Iris MVC 路由约束

请检查接口 URL 与 Iris MVC 实际路由是否一致，并严格遵守以下规则：

1. 文档 URL 是最终契约，代码必须服务文档 URL。
2. URL 包含短横线时必须使用 `BeforeActivation` 显式绑定。
3. 新增接口后必须用文档 URL 做本地 curl 验证。

## 1. 用户消息列表

```text
GET /api/message-notify/list
```

认证：需要登录。

查询参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| businessCode | string | 否 | 业务分类 |
| status | int | 否 | 0 未读，1 已读 |
| cursor | int64 | 否 | 游标，首次传 0 |
| limit | int | 否 | 默认 20，最大 100 |

返回 data：

| 字段 | 类型 | 说明 |
|------|------|------|
| results | array | 消息列表 |
| cursor | string | 下一页游标 |
| hasMore | bool | 是否有更多 |
| unreadCount | int64 | 当前用户未读总数 |

消息项字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int64 | 消息 ID |
| businessCode | string | 业务分类 |
| templateCode | string | 模板编码 |
| subject | string | 标题 |
| body | string | 正文 |
| detailUrl | string | 跳转链接 |
| status | int | 0 未读，1 已读 |
| extraData | string | 扩展数据 JSON |
| createTime | int64 | 创建时间 |

## 2. 未读数量

```text
GET /api/message-notify/unread-count
```

认证：需要登录。

返回 data：

| 字段 | 类型 | 说明 |
|------|------|------|
| totalUnread | int64 | 未读总数 |
| businessUnread | object | 按业务分类聚合的未读数 |

## 3. 消息详情

```text
GET /api/message-notify/by/{id}
```

认证：需要登录。

路径参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | int64 | 是 | 消息 ID |

规则：

- 只允许读取当前用户自己的消息。
- 不自动标记已读。

## 4. 标记单条已读

```text
POST /api/message-notify/read
```

认证：需要登录。

请求格式：JSON。

请求体：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | int64 | 是 | 消息 ID |

返回 data：

| 字段 | 类型 | 说明 |
|------|------|------|
| updated | bool | 本次是否从未读更新为已读 |
| record | object | 消息记录 |

## 5. 批量已读

```text
POST /api/message-notify/read-batch
```

认证：需要登录。

P1 实现。

请求体：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| ids | int64[] | 否 | 消息 ID 列表 |
| businessCode | string | 否 | 业务分类 |
| all | bool | 否 | 是否全部已读 |

规则：

- `ids`、`businessCode`、`all=true` 三种方式至少传一种。
- 仅更新当前用户的未读消息。

## 6. 公共推送方法

非 HTTP 接口，由业务服务调用。

```go
MessageNotifyService.PushByTemplate(ctx, input)
```

输入：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| BusinessCode | string | 是 | 业务分类 |
| TemplateCode | string | 是 | 模板编码 |
| UserId | int64 | 是 | 接收用户 |
| Params | map[string]string | 是 | 模板参数 |
| ExtraData | map[string]any | 否 | 扩展数据 |
| BizId | string | 否 | 业务对象 ID |
| IdempotencyKey | string | 否 | 幂等键 |

错误码：

| 错误码 | 触发条件 |
|--------|----------|
| MESSAGE_NOTIFY_DISABLED | 总开关关闭 |
| TEMPLATE_NOT_FOUND | 模板不存在 |
| TEMPLATE_DISABLED | 模板禁用 |
| TEMPLATE_PARAM_MISSING | 必填模板参数缺失 |
| TEMPLATE_RENDER_FAILED | 模板渲染失败 |
| USER_ID_REQUIRED | userId 非法 |
