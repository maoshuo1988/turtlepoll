# 主站消息外部特性依赖详情

## EXT-001 用户登录与当前用户识别

- 接口名：`common.GetCurrentUser`
- 调用方向：主站消息接口 -> 登录认证模块
- 调用方式：服务端从 Iris Context 读取登录态

输入参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| ctx | iris.Context | 是 | 当前请求上下文 |

输出参数：

| 字段 | 类型 | 说明 |
|------|------|------|
| user | User | 当前用户对象 |

错误码：

| 错误码 | 触发条件 |
|--------|----------|
| NOT_LOGIN | 当前请求未携带有效登录态 |

固定策略：

- 所有 `/api/message-notify/**` 用户接口必须要求登录。
- 未登录响应必须是 JSON，不允许落到前端 HTML fallback。

验收标准：

- 未登录访问列表接口返回未登录错误。
- 登录用户只能读取本人消息。

## EXT-002 宠物每日登录结算

- 接口名：`PetDailySettleService`
- 调用方向：登录成功链路 -> 宠物模块 -> 主站消息服务
- 调用方式：服务内方法调用

输入参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | int64 | 是 | 登录用户 ID |
| dayName | int | 是 | 北京时间日期，如 20260711 |

输出参数：

| 字段 | 类型 | 说明 |
|------|------|------|
| items | array | 每日结算明细 |
| balanceAfter | int64 | 结算后余额 |
| alreadySettled | bool | 今日是否已结算 |

错误码：

| 错误码 | 触发条件 |
|--------|----------|
| ALREADY_SETTLED | 同一用户同一天已结算 |

固定策略：

- 仅当首次结算且奖励金额大于 0 时推送。
- 幂等键固定为 `daily_login_reward:{userId}:{dayName}`。
- 结算失败不阻断登录，也不生成消息。

验收标准：

- 同一用户同一天最多生成一条 `daily_login_reward` 消息。

## EXT-003 预测下注结算

- 接口名：`PredictSettleService.SettleMyBet`
- 调用方向：预测市场模块 -> 主站消息服务
- 调用方式：服务内方法调用

输入参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | int64 | 是 | 结算用户 ID |
| marketId | int64 | 是 | 预测市场 ID |

输出参数：

| 字段 | 类型 | 说明 |
|------|------|------|
| bet | PredictBet | 已结算下注单 |
| payout | int64 | 派奖金额 |
| userCoin | UserCoin | 用户金币账户 |

错误码：

| 错误码 | 触发条件 |
|--------|----------|
| MARKET_NOT_SETTLED | 市场未进入 SETTLED |
| MARKET_RESULT_INVALID | 市场结果不合法 |

固定策略：

- 下注单从 OPEN 变 SETTLED 后生成消息。
- 幂等键固定为 `predict_settle:{betId}:{settleResult}`。
- 同一 betId 同一结果最多一条消息。

验收标准：

- 命中下注生成 `predict_settle_win`。
- 未命中下注生成 `predict_settle_lose`。

## EXT-004 用户金币账户

- 接口名：`UserCoinService`
- 调用方向：宠物/预测业务 -> 金币账户模块
- 调用方式：服务内方法调用

输入参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | int64 | 是 | 用户 ID |
| amount | int64 | 是 | 金额 |
| bizType | string | 是 | 业务类型 |
| bizId | int64 | 是 | 业务 ID |

输出参数：

| 字段 | 类型 | 说明 |
|------|------|------|
| balance | int64 | 当前余额 |
| coinLogId | int64 | 金币流水 ID |

错误码：

| 错误码 | 触发条件 |
|--------|----------|
| INSUFFICIENT_BALANCE | 余额不足 |
| AMOUNT_INVALID | 金额小于等于 0 |

固定策略：

- 消息只记录已完成的资金结果。
- 消息不能作为资金入账依据。

验收标准：

- 消息金额与业务返回金额一致。

## EXT-005 旧论坛站内信

- 接口名：`MessageService`
- 调用方向：主站消息聚合演进 -> 旧消息模块
- 调用方式：服务内查询

输入参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | int64 | 是 | 用户 ID |

输出参数：

| 字段 | 类型 | 说明 |
|------|------|------|
| unreadCount | int64 | 旧站内信未读数 |
| messages | array | 旧站内信列表 |

错误码：

| 错误码 | 触发条件 |
|--------|----------|
| DB_ERROR | 数据库查询失败 |

固定策略：

- MVP 不聚合旧站内信。
- P1 评估统一未读角标。

验收标准：

- MVP 不影响旧 `/api/user/messages` 行为。

## EXT-006 AI 主动推送

- 接口名：`AIPushService`
- 调用方向：主站消息聚合演进 -> AI 模块
- 调用方式：服务内查询或既有 HTTP 接口

输入参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | int64 | 是 | 用户 ID |
| limit | int | 否 | 拉取数量，默认 20，最大 100 |

输出参数：

| 字段 | 类型 | 说明 |
|------|------|------|
| results | array | AI 未读推送列表 |

错误码：

| 错误码 | 触发条件 |
|--------|----------|
| NOT_LOGIN | 未登录 |

固定策略：

- MVP 不迁移 AIMessage。
- P1 评估聚合展示。

验收标准：

- MVP 不影响 `/api/ai/pushes/unread` 与 SSE。
