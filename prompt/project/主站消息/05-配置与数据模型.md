# 主站消息配置与数据模型

## 1. 状态枚举

### 1.1 模板状态

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | disabled | 禁用 |
| 1 | enabled | 启用 |

### 1.2 用户消息状态

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | unread | 未读 |
| 1 | read | 已读 |

## 2. t_message_notify_template

消息通知模板表。

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | bigint | 是 | 主键 |
| business_code | varchar(64) | 是 | 业务分类 |
| template_code | varchar(128) | 是 | 场景模板编码 |
| subject_template | varchar(255) | 是 | 标题模板 |
| body_template | text | 是 | 正文模板 |
| detail_url_template | varchar(512) | 否 | 跳转链接模板 |
| template_params | text | 是 | JSON 数组，声明必填参数 |
| status | int | 是 | 0 禁用，1 启用 |
| remark | varchar(512) | 否 | 运营备注 |
| create_time | bigint | 是 | 创建时间，Unix 秒 |
| update_time | bigint | 是 | 更新时间，Unix 秒 |

唯一约束：

- `uk_message_notify_template_biz_tpl(business_code, template_code)`

索引：

- `idx_message_notify_template_status(status)`

## 3. t_user_message_notify_record

用户消息通知记录表。

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | bigint | 是 | 主键 |
| business_code | varchar(64) | 是 | 业务分类 |
| template_code | varchar(128) | 是 | 场景模板编码 |
| template_id | bigint | 是 | 模板 ID |
| user_id | bigint | 是 | 接收用户 |
| subject | varchar(255) | 是 | 渲染后的标题 |
| body | text | 是 | 渲染后的正文 |
| detail_url | varchar(512) | 否 | 跳转链接 |
| status | int | 是 | 0 未读，1 已读 |
| template_params | text | 否 | 本次参数 JSON 快照 |
| extra_data | text | 否 | 扩展业务数据 JSON |
| biz_id | varchar(128) | 否 | 业务对象 ID |
| idempotency_key | varchar(191) | 否 | 幂等键 |
| create_time | bigint | 是 | 创建时间，Unix 秒 |
| update_time | bigint | 是 | 更新时间，Unix 秒 |

唯一约束：

- `uk_user_message_notify_idem(user_id, idempotency_key)`

索引：

- `idx_user_message_notify_user_time(user_id, create_time, id)`
- `idx_user_message_notify_user_status(user_id, status)`
- `idx_user_message_notify_user_business(user_id, business_code, create_time)`
- `idx_user_message_notify_biz(business_code, template_code, biz_id)`

## 4. 字段约束

- `business_code` 必须来自固定字典。
- `template_code` 只能使用小写字母、数字和下划线。
- `subject` 最大 255 字符。
- `body` 不允许为空。
- `detail_url` 存储渲染后的相对路径。
- `idempotency_key` 为空时允许多条记录。

## 5. PushByTemplate 输入模型

```go
type MessageNotifyPushInput struct {
    BusinessCode   string
    TemplateCode   string
    UserId         int64
    Params         map[string]string
    ExtraData      map[string]any
    BizId          string
    IdempotencyKey string
}
```

## 6. PushByTemplate 输出模型

```go
type MessageNotifyPushResult struct {
    RecordId int64
    Created  bool
    Record   *MessageNotifyRecord
}
```

## 7. 默认配置

| 配置 | 默认值 | 说明 |
|------|--------|------|
| messageNotify.enabled | true | 主站消息推送总开关 |
| messageNotify.defaultPageSize | 20 | 列表默认分页 |
| messageNotify.maxPageSize | 100 | 列表最大分页 |
| messageNotify.renderStrict | true | 渲染后存在未替换占位符即失败 |
| messageNotify.readUpdateThrottleSeconds | 0 | 已读更新不做频控 |
